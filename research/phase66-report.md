## 1. 预注册（跑之前写死）

### 1.1 诊断：新生儿支系（age < 10k）的 mate_misses 构成

**构建**：`CladeLifeStats` 增加 6 个纯计数列（`mate_miss_no_kin / other_region / beyond_radius / filtered / other` + young 版本）、`dispersal_out`、`deaths_off_region`、kind/region 人口和、`beyond_radius` 所需距离和。`mate_miss_bucket()` 在 `nearest` 返回空之后按「什么能救这一对」重扫一次世界（只读）：

| 桶 | 判定（互斥，按此优先级） | 语义 |
|---|---|---|
| `no_kin` | 全世界没有同 kind 的其它活体 | 扩大半径/同区域招募都无解，只能等新支系 |
| `other_region` | 有同 kind，但母亲的 `region` tag 内一只都没有（仅 `region_isolation` 开时） | 区域隔离闸卡住；只有跨区域招募能治 |
| `beyond_radius` | 同区域有**可育**同 kind，但最近一只也在半径外 | 半径是唯一约束 |
| `filtered` | 同区域、半径内有同 kind，但全部不过年龄/冷却/能量闸 | 能量/成熟度约束，半径无用 |
| `other` | 同区域有同 kind，但全部「不可育且在半径外」 | 半径与生育闸同时卡住 |

其余读法：

- 派生支系占 DECO 全部 mate_misses 的 **63.1 %**（3 016 351 / 4 780 563）；根 clade 占 36.9 %。
- 新生儿窗口（age<10k）的构成与全生命期一致：`beyond_radius` 64.8 %、`other_region` 11.8 %、`filtered` 8.9 %、`other` 14.5 %、`no_kin` 0 %。这不是「老支系才有的病」。

**诊断结论**：77.8 % 的派生支系失败（`beyond_radius` + `other`）是「同区域里有同族，但都在搜索半径外」；14.1 % 是区域隔离；8.2 % 是生育闸；**0 % 是「全世界没有同族」**。

### 1.2 由诊断选候选：为什么是候选 1，不是 2/3

| 候选 | 最多能治的桶 | 占比 | 判定 |
|---|---|---|---|
| **1 择偶半径** | `beyond_radius` + `other`（半径部分） | **77.8 %** | **选它** |
| 2 招募信号（跨区域迁移） | `other_region` | 14.1 % | 不对主桶；且要改 Phase 47 的扩散/优先效应，风险大于收益 |
| 3 留存（能量地板 / 迁移抑制） | `filtered`（能量）/ `other_region`（迁移） | 8.2 % / 14.1 % | 能量地板是变相补贴（Phase 65 W2 的否证理由）；迁移抑制的 `dispersal_out` 只有 142–212 次/200k，量级不足 |

**一个必须先说清的算术**：现有 Allee 缓解（Phase 42.1）已经把半径从 11 扩到 **44**（零密度时 4× 基础半径）。任务建议的「上限 3× 基础半径 = 33」**比现行实现还小**，不能作为候选。实测 `beyond_radius` 所需距离均值 **274.2**，是 44 的 6.2 倍——所以 R1 必须按「区域 deme 的空间尺度」重定，而不是在 11–44 之间调参。

**作用域论证（为什么只给派生 kind）**：

1. 根 kind 是 Phase 47/60 的 4 象限岛模型分化引擎（Phase 62 §3 的 13 起灭绝全部来自派生支系）；动根的半径会直接改写分化引擎，Phase 61 候选 a 已经演示过这条路的代价（0 分化、DECO 回满 80）。
2. 派生支系的密度极低：每次 miss 时同区域同 kind 人口均值 5.3（含母亲自己），正是 Allee 陷阱的定义域。
3. **区域隔离闸不变**：配偶 filter 仍要求 `b.region == a.region`，子代仍继承母方 `region` tag。因此跨象限基因流在构造上仍然不可能；本机制只把「同一 deme 内的可搜索范围」放大。这把 Phase 47 的隔离/分化风险降到最低。

### 1.3 机制 R1 / R2（语义写死）

| 项 | 值 |
|---|---|
| 编译默认 | `MATE_FLOOR_ON = false`（臂旋钮 `mate_radius_arm = 0`） |
| 作用对象 | 仅 `kind_def(kind).parent_kind.is_some()`（派生 kind）；FISH / 根 kind / 六族祖先完全不变 |
| 密度量 | `n = region_count(kind, a_region)`（同 tag 的活体，含母亲；下限 1） |
| 地板 | `floor = min(REF × sqrt(N_REF / n), MAX)`，`N_REF = 4` |
| 半径 | `radius = max(legacy, floor)`；`legacy = 11 × (1 + (1 − d) × 3)`，`d = count(kind) / biome_cap_in(kind, biome)`（Phase 42.1 原式）；FISH 仍 60 |
| R1 | `REF = 300`，`MAX = 320` |
| R2 | `REF = 420`，`MAX = 420` |

|---|---|---|---|---|---|---|---|---|---|

| R2 | 420（截） | 420（截） | 420（截） | 420 | 376 | 343 | 297 | 243 | 210 |

**边界（写死）**：

| 情况 | 处理 |
|---|---|
| `floor ≤ legacy` | 逐位退回 legacy；D0 不记 boost |
| 根 kind / FISH | 永不进入地板分支 |
| 支系只有母亲 1 只 | `n = 1` → `REF × 2` 再截断到 MAX |
| 半径变大但配偶在别的 region tag | filter 仍拒绝；`region_isolation` 语义不变 |
| 半径内最近的配偶 | 仍然是 `nearest` 的几何最近者，**不是**随机选择；零 RNG |
| 出生位置 | 不变（母方 home + jitter）；机制只改搜索上界 |
| 存档 | 不入档（与 `fork_budget_min` / `grace_ticks` 同契约）；读档回编译默认 OFF |
| 守恒 | 不改任何预算/能量/槽位；`family total` 恒等式不受影响 |

### 4.7 读法（为什么这是负结果，而不是实现失败）

1. **机制确实咬到了，而且咬得很深**：972 万次搜索被抬高半径、196 万次在 legacy 半径外成配；`beyond_radius` 桶从 67.6 % 降到 46.2 %。这不是「仪器没响」。
2. **分化是零和**：35 → 35，但逐 seed 从 +3 到 −6。地板不系统性地提升或压低分化，它重新分配「哪个 seed 在什么时候分叉」。80k 快筛看到的 15 → 11 是同一个盆地噪声的另一抽签。
3. **存活变差**：灭绝 13 → 16（+23 %），反向 2/5。出生/死亡几乎不变（+0.8 % / +0.6 %），说明地板没有创造新生物量；它只是把「成配」提前，让支系更快撞上容量闸。
4. **P3a 差 8.5 个百分点**：−41.5 % 未到 −50 %。原因是总 miss 的分母被 clade-ticks 污染——R1 下支系活得更久（3 569 280 vs 3 784 106 clade-ticks，−6 %），而每个 clade-tick 的 miss 率降了 38 %（868 vs 1398）。**总量指标在臂间 clade 数不同时不可比**，这是本期的方法论教训（Phase 67 应改用 miss/clade-tick 或 miss/birth）。
5. **与 Phase 62 的定因表一致**：容量闸拒绝 99.9 % 的出生尝试；把择偶修好只是让被拒的尝试更多（`kind_budget_blocks` +4.6 %）。「招募不足」是容量的另一面，不是独立杠杆——这一条现在有了直接实验证据。

## 5. 决策

**不通过 → 默认保持 OFF；不 re-baseline（锚点不变）。**

两条独立依据：

1. **§1.9 快筛门**：R1 `Σ spec = 11 < 0.90 × 15 = 13.5`；R2 `7`。设计在 80k 被否，按 §1.12 的声明，200k 只作失败模式诊断，默认值不因它改变。
2. **§1.7 判定**（200k 5 seed）：P1 过（35/35），**P2 败**（16 > 9.75），**P3a 败**（0.585 > 0.50），D0 过。按决策表第 4 行（P2 败）→ OFF。

### 5.1 保持了默认世界

- `MATE_FLOOR_ON = false` 未动；默认轨迹与 Phase 65 逐位一致。
- 第二十次 re-baseline **没有发生**：@300 / @3000 / @30000 / @60000 全部不变（§6）。
- 臂保留：`PHASE_MATE_FLOOR=r1|r2` 可在任意 seed 上复跑；`mate_radius_arm` 不入档，读档回 OFF，`SaveState` 仍为 v24。

### 5.2 没有证明什么（诚实边界）

- **没有证明「所有择偶半径设计都有害」**：R1 是 150–320 的大地板。OFF 臂的 `min_ready_dist` 几乎每个 clade 都恰好是 **44.00**（legacy 上限 + ε），说明失败分布里有一个「只差一点点」的尖峰；一个 80–120 的小地板是完全不同的设计，本期没有测。
- **没有证明招募/留存整体无效**：只测了「派生支系的区域内择偶半径」这一个通道。跨区域招募（`other_region` 19.9 %）与迁移家庭重标签（`dispersal_out` 924–1 006 次/5 seed）未测。
- **没有证明 P1 的零和是规律**：5 seed 的逐 seed 符号从 +3 到 −6，合计恰好 0；样本分辨率不足以排除小幅系统性效应。
- **没有把 P2 的 +23 % 归因到单一通道**：出生/死亡只动 0.8 %，容量闸拒绝动 5 %；灭绝增加与「更多女儿 + RNG 流分岔」纠缠在一起。试读：地板把「成配」提前，让支系更快撞上容量闸并更快耗散——这与 Phase 62 §3.2 的「容量饥饿是主因」一致。
- **80k 快筛的 15 → 11 是一抽签**：200k 上同一机制是 35 → 35。3 seed × 80k 不足以给 spec 设门（Phase 65 §11.5 的 5-seed 结论在这里再次成立）。
