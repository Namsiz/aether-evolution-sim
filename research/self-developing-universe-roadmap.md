## 0. 定位与「涌现 vs 脚本」判断标准

**一句话愿景**：把「物种、基因、行为、食性、社会、技术」从代码常量全部降级为**可变异、可组合、可被能量账本定价、可繁殖传递的运行时数据**；代码只保留两类东西——物理定律（能量/信息/几何约束）与演化算子（变异/选择/漂变/分裂）——使「新物种 → 智能 → 文明 → 超越人类」成为数据在能量约束下被筛选的涌现结果，而不是任何 `match kind` 分支的产物。

**不在本路线图范围内**：
- 观察层任何新功能（overlay/HUD/图表/渲染效果）——用户已冻结；必要的数据导出接口（研究用 headless 导出）例外，理由见 §3 各阶段「契约影响」。
- 玩家角色、干预工具、目标导向的"任务"——世界不为玩家设计。
- 预设科技树、预设文明阶段、写死的新物种模板——直接违反铁律 1。
- 化学分子层（组合化学/超循环）：按 scout 报告 §Q6 推迟——生态层的演化丰富性来自机制条件而非底层保真度（Tierra/Avida 先例）；等到"生命起源弧线"或"发明/材料层"真实需要时，优先 RAF 图模型（Kauffman/Steel 可判定框架）而非浓度 ODE。
- LLM/外部非确定智能进 sim 核心：破坏 bit-exact（scout 报告 §Q5 对 Project Sid 的结论）；若未来用于"观察者叙事"，只放 sim 外环。

**每个机制的验收三问（写进 code review checklist）**：
1. **可遗传变异**：该机制的关键参数是否有可突变、可遗传的载体（基因/知识/结构），还是写死在常量里？
2. **能量可定价**：获得该能力是否有持续的、可被自然选择衡量的成本（upkeep / 传输 / 存储）？
3. **结果不写死**：达成与否是否由演化自己走？任何「达到 X 就触发 Y 新形态」的硬编码都是脚本。

外加一条**望远镜纪律**（scout 报告最高优先级建议 1）：一切涌现指标（智能、文明、复杂度）只做遥测，绝不回写 sim 逻辑——**度量是望远镜，不是鞭子**。

> 用三问回测现有机制：配子屏障 + 涌现式选型交配（`ecology.rs:1852-1863`）、MST 分化检测（`ecology.rs:3555`）、竞争排斥（`niche.rs:73-113`）都合格——它们是**测量仪器**（宣告发生了什么），不是**剧本**（迫使发生什么）；而「濒危捕食者移民」（`ecology.rs:3071-3085`）和 HERB 谱系的 `speciation_fired < 3` 限流（`ecology.rs:3257`）是剧本，见 §1。地质地震从板块碰撞动力学内生涌现（`geology.rs:232-238`），不是"每 N tick 陨石"式上帝脚本——这个模式是合法的。

## 1. 封顶点诊断（Cap-Point Audit）

以下每一项都经源码核实，标注它挡住通往「新物种 → 智能 → 文明 → 超越人类」的哪一步。

### 1.1 封顶点清单

**C1 · 六固定物种 kind + 行为按 kind 分支硬编码**
- 证据：`core/crates/aether-sim-ecology/src/ecology.rs:16-21` 定义六个 `&'static str` 常量；`ecology.rs:145` `Agent.kind: &'static str`（编译期固定，运行时无法新增）；主循环按 kind 硬编码分发 `ecology.rs:3028-3034`（`HERB => update_herb … _ => update_pred`）；至少五处 `match kind` 以 `unreachable!()` 收尾——`ecology.rs:924,933`（biome_max_for）、`ecology.rs:1757,1775`（reproduce）、`ecology.rs:1933`（die 的 fitness 槽位）、`ecology.rs:2094`（拥挤惩罚）——**新增 kind 会直接 panic**。
- 挡住：**新物种**（第一步就断）。任何新躯体计划、新行为模式需要改代码重新编译；行为永远无法成为选择压力的素材。这是全部封顶中最硬的一条。
- 附带封顶：`ecology.rs:614-615` `evolution/generation_fitness` 是 `[..; 6]` 固定六槽数组；`ecology.rs:3851` checksum 只混入 kind 名**首字节**（>256 个物种即身份碰撞）。

**C2 · 基因组固定 17 维**
- 证据：`ecology.rs:121-136` `Genome` 为编译期定长 struct；`mutate`（`ecology.rs:1227-1263`）按字段写死突变 σ 与 clamp；`mix_genome`（`ecology.rs:1265-1291`）写死逐字段平均；`random_genome`（`ecology.rs:1150-1225`）按 kind 写死初始区间。
- 挡住：**新形态 → 智能的器官基底**。没有为"脑"“新感官”“新器官”预留的基因座，任何新功能性状无处突变；表现型空间是常数维的。对照 OEE 四条件（scout 报告 §Q1）：条件①"可能出现新的可遗传特征"直接不成立。

**C3 · MAX_* 容量上限**
- 证据：`ecology.rs:29-34`：HERB 420 / PRED 110 / SCAV 40 / OMN 80 / FISH 60 / DECO 80；`spawn` 硬性拦截 `ecology.rs:1294-1295`；繁殖密度刹车 `ecology.rs:1748-1790`；**全局安全阀** `ecology.rs:3089-3092`（总量 790+60 截断，按年龄杀最老者）。
- 挡住：**辐射演化与数量级发展**。所有食肉者后裔共享 MAX_PRED=110——哪怕分化出 20 个肉食物种，合计也不能超过 110 只；能量通量（文明的 Kardashev 式度量）被人口上限锁死在"山谷级"。

**C4 · MST 分化：单轴、单物种、静态阈值、HERB 侧脚本化**
- 证据：`ecology.rs:300-312` 四个阈值常量（检查间隔 60 tick / 距离 0.35 / 地理 100m / 冷却 200 tick / 每侧最少 2 只）；检测器**只跑 DECO**：`ecology.rs:3466` `filter(|(_, a)| a.alive && a.kind == DECO)`；距离只在 **1 维 deco_efficiency 轴**上度量：`mst_edges_1d` `ecology.rs:3409`；HERB 侧旧分化带脚本性质：`ecology.rs:3218`「Speciation detection for HERB only」、`ecology.rs:3257` `speciation_fired < 3` 限流、谱系名写死「迅聚/缓独」（`ecology.rs:3276-3296`）。
- 挡住：**真正的物种多样化**（OEE 条件③"多样性的变化"）。一个物种的分化不能发生在它的主要适应轴（速度/感官/体型/社会性）上，只能发生在 DECO 的效率轴上；HERB 的"分化"最多发生 3 次且名字是预设的。
- 说明：阈值本身作为**测量仪器**是合法的（宣告"这算两个物种"），静态性不是问题；问题是**轴**与**适用范围**被写死。

**C5 · 草三物种枚举**
- 证据：`ecology.rs:102-107` `GRASS_SPECIES: [GrassSpecies; 3]`、`GRASS_N = 3`；整个引擎围绕定长 3 层组织：`grass_p/suit_eff_by: [Vec<f32>; GRASS_N]`（`ecology.rs:599-602`）、`taken_buf: [f64; GRASS_N]`（`ecology.rs:617`）；存档硬断言 `grass_by_species.len() == GRASS_N`；RenderPacket 约定 `sp ∈ [0,3)`（`core/crates/aether-render-packet/src/lib.rs:135-140`）且 cargo 定长 `vec![0.0; 3]`（同文件 `:206`）。
- 挡住：**植物多样化 → 农业/驯化 → 生态位构造**。生态系统的生产层永远只有 3 个物种；scout 报告 §Q4 的农业先例（Bowles & Choi 2013：技术⇄产权协同演化）需要作物层可扩展才有落脚点。

**C6 · 食物关系硬编码（谁吃谁写死）**
- 证据：HERB 只吃草（`update_herb` → `take_grass`，`ecology.rs:2116-2128`）；PRED 只吃 HERB 或 FISH（`ecology.rs:2172-2182` `fish_reachable` 二选一逻辑）；SCAV 尸体+草（`ecology.rs:2333-2414`）；OMN 尸体+草、怕 PRED（`ecology.rs:2434-2540`）；FISH 只在 aquatic biome 内吃草 + 免费滤食增益 `FISH_FILTER_GAIN=1.5`（`ecology.rs:62`、`ecology.rs:2679-2683`）；DECO 尸体独食（`ecology.rs:2702`「Carcass-only diet」）。没有"食性"这一可突变性状，没有营养级关系的运行时表达。
- 挡住：**营养级演化 → 杂食/共生/捕食策略演化**。生态位的"职业"是出生证上写死的。营养级能量塔（Lindeman ~10% 传递效率，scout 报告 §Q6）既无法表达、也无必要存在——因为没有食物链可言。

**C7 · 社会机制 kind 限定**
- 证据：间接互惠 `try_help` 仅 HERB（`ecology.rs:1571` `if self.agents[a_idx].kind != HERB { return false; }`）；信号匹配仅 HERB×HERB（`ecology.rs:1852`）；冬季聚合仅同类（`ecology.rs:1626-1633`）。
- 挡住：**社会演化 → 文化 → 文明**。其他谱系即使演化出合作的基因型也没有执行的代码路径；"谁可以有社会"是物种出生时决定的。这是 scout 报告 §Q2/§Q4（大跃迁、文化演化）路径在 C7 处被整体切断。

**C8 · 单山谷单世界**
- 证据：`ecology.rs:23-24` GRID_N=76 × GRID_SPAN=1080（5776 格）；`terrain.rs:12` SIM_RADIUS=560；地形 Perlin 排列表硬编码（`terrain.rs:28`）；单一 `Ecology` 实例；v2.0 的 `aether-coords`（参考系树）与 `aether-clock`（分层时钟）crate 已建成但**未被 sim 接线**（全仓 grep 仅测试引用）。
- 挡住：**地理尺度的分化、迁徙、文明扩张空间、资源梯度**。一块 1km 山谷装不下文明的地理学（scout 报告 §Q5 引 Turchin 2013：帝国兴衰由地理+资源+战争扩散的少数参数决定——单山谷里这些自由度不存在）。

**C9 · 神之手脚本（god-hand scripts）**
- 证据：濒危捕食者移民——PRED<5 时以 p=0.002 从天而降新个体（`ecology.rs:3071-3085`）；`seed_life` 的固定 18 只兽群坐标（`ecology.rs:1018-1046`，初始布景，性质上可接受，列为待迁移项）。
- 挡住：**演化的真实性**。灭绝被剧本阻止，选择压力被噪声化；OEE 文献一致要求机制内生（scout 报告 §Q1"已知坑"：扰动必须从世界规则涌现）。对照：geology 的地震从碰撞动力学内生（合法），immigration 是外生救援（不合法）。

**C10 · 能量会计不守恒**
- 证据：草→肉转换常数按 kind 写死（62.0/55.0/58.0，`ecology.rs:2122,2411,2520`）；尸体能量以 1.4/tick 蒸发（`ecology.rs:3047-3050`）去向不明；FISH 滤食是免费输入（`ecology.rs:2621`）；捕食收益 `gain*0.8` 与尸体能量 `gain*0.22` 之和与猎物携带能量无恒等关系（`ecology.rs:2271-2280`）；各 drain 公式（`ecology.rs:2086-2091` 等）不共享账本。
- 挡住：**热力学收支 → Kardashev 度量的可信性 → 智能的能量定价**。scout 报告 §Q3/Q6 的核心工程建议（脑按神经元数收费、学习按次收费、MTE 统一账本）全部以一本闭合的能量账为前提——账本不闭合，"聪明"的成本就是一句空话。

**C11 · 行为状态机写死**
- 证据：`Agent.state: &'static str`（`ecology.rs:146`），状态集合 `{wander, graze, flee, hunt, scavenge, patrol, school, approach, eat, feed, search}` 全部由各 `update_*` 的过程代码实现；行为不存在"参数化"之外的变异通道。
- 挡住：**行为层面的演化空间**（工具使用、筑巢、玩耍、欺骗、教学等新行为无生成机制）。

**C12 · 个体规模的 O(n²) 感知与无空间索引**
- 证据：`nearest` 全表线性扫描（`ecology.rs:1441-1466`）、`try_help` 全群扫描（`ecology.rs:1589-1601`）；当前 ~800 个体 × 单线程 WebView 下可接受，但任何"无上限"的物种数都会先撞这堵墙。
- 挡住：**不是概念封顶，是工程封顶**——必须在数量级增长前准备好（见 §2.6 与 Phase 31/38）。

### 1.2 值得保留的资产（如实表扬，不拆）

- **确定性加层的成熟模式**：专用 RNG 流隔离（`fish_rng`、`GEO_RNG_TAG`）+ 新层"零 RNG 纯记账"（niche/cataclysm/speciation/geology/biochem 全部零 RNG 或专流，且**基线态位精确无副作用**——`FAST_BASELINE` 使 `x*1.0` 位精确，`biochemistry.rs:28-36`）。这是后续每个新层（脑、文化、账本）都必须复用的模式，已被 Phase 16-18 反复验证。
- **clade 登记无上限**：`species_clades: Vec`、`next_clade_id: u32` 递增、化石永久保留（`ecology.rs:633-636`、`ecology.rs:3487-3553`）——物种数本身没有封顶，封顶在检测器（C4）。
- **BiomeRegistry 已参数化**：每 biome 的容量覆盖、家域修正（`core/crates/aether-biome/src/lib.rs:17-36`）——空间异质性钩子已存在，缺的是把"每 kind 一字段"改成"每 kind-id 一条记录"（C1）。
- **存档 additive 版本演进**：SaveState v1→v5 全程 `#[serde(default)]` 向后兼容（`save_state.rs:28-41`）——schema 演进模式已定型。
- **机制级测试注入模式**：`kill_kind`/`inject_mineral`/`set_geo_plates`（`ecology.rs:3938-3952`、`geology.rs:536-558`）——A/B 实验方法学已定型，正是"涌现验证"在观察层冻结下的主力手段。
- **适应度天然不可显式**：agent 只有能量/繁殖/死亡，没有任何物种评分——OEE 条件④（minimal criterion）已经是现状（scout 报告 §Q1 建议 1），只需守住不退步。

## 2. 目标架构（核心概念层）

**为什么**：所有"封顶"的共同根源是**把演化本该拥有的自由度放在了编译期**。解法不是加大枚举，而是把自由度移到运行期数据。

### 2.1 通用生命表征：从固定 17 维到可扩展基因组

三个候选方案的取舍（问题：新物种/新形态/新行为如何**不用改代码**就出现）：

| 方案 | 内容 | 无上限程度 | 确定性 | 性能 | 迁移成本 | 判定 |
|---|---|---|---|---|---|---|
| **A 可变基因座向量** | 基因组 = 定长核心座（现有 17 维原样保留）+ 有序开放基因座 `Vec<Locus>`；突变算子含**基因重复**（duplication，新基因座的唯一合法来源）与缺失 | 高：座数无上限，功能空间开放但"每个座是什么"仍需解释子 | 高：座表有序、突变按固定序遍历、每座固定 draw 数 | 中：座数增长受表达维护成本自发抑制 | 中：SaveState/对拍协议需扩展 | **选为基底** |
| **B 模块化基因（调控 + 模块）** | 在 A 之上加两类座：**模块座**（代谢/感知/效应/脑/行为，各带自己的参数子座）与**调控座**（决定哪些模块在发育中表达、复制倍数、接线权重）——Hox 式的"躯体计划即基因" | 最高：连"长几个器官、怎么接"都进演化 | 高（同 A，层级序固定） | 中低：发育解释子每 tick 跑一次缓存表现型 | 高：需要发育解释器，但正好吸收掉 C1 的六个 `update_*` | **选为目标形态**（Phase 36 后期） |
| **C 行为参数基因化** | 保留现有 FSM，把过程代码里的所有常数（咬合间隔、转向速率、家域、帮扶阈值…）搬进基因组变成可突变参数 | 低：**行为空间仍被状态集合封顶**，单独采用违反铁律 1 | 高 | 高 | 低 | **只作桥接**（Phase 31-33 的过渡态，不得是终态） |

裁决逻辑：**C → A → B 是同一条演化路线的三个里程碑**，不是三选一。Phase 31 先把六 kind 的过程常数全部数据化（C，同时消灭 C1）；Phase 32 建 A 的开放座机制（重复突变是"新基因从哪来"的现实规律答案——Ohno 的基因重复学说，scout 报告 §Q2 同构于大跃迁"信息存储方式改变"）；B 作为智能层落地后的自然产物（脑模块本身就是一个模块座），不提前设计。确定性要点：**座向量按 id 有序**；突变遍历顺序 = 座表顺序；每座 draw 数固定（draw-then-clamp，无数据相关的 draw 计数）；重复/缺失事件由固定预算的 draw 槽决定（详见 §4）。

对照 OEE 四条件（scout 报告 §Q1，Chromaria 消融验证）：A 补齐条件①（新的可遗传特征可出现）；Phase 34 的多轴分化补齐条件③（多样性的变化）；Phase 37 的生态位构造补齐条件②（"变化带来进一步变化的潜能"——scout 建议：把新颖性压力外包给生态位构造，即 POET 的生态版）；条件④已是现状（§1.2 末条）。

### 2.2 能量与信息基底

**为什么**：铁律 3 要求"用规律代替脚本"——热力学与信息论是两条最硬的规律，而且它们天然给出"成本"：**没有成本就没有选择，没有选择就没有涌现**。

- **统一能量账本（Energy Ledger）**：全 sim 只有一本账。每 tick 恒等式 `Σ摄入 = Σ生物质增量 + Σ做功 + Σ废热 + Σ储存`；每一个现存魔数（62.0 转换、1.4 尸体蒸发、滤食增益）要么变成显式输入场（初级生产力——阳光驱动的草生长已是事实上的输入边界），要么变成显式损耗（尸体蒸发 → 腐殖质池，正好接 biochemistry 的 fast/slow 池）。账本先做**记账重构**（数值不变、只是归类），再做**守恒收紧**（数值改变，一次性 re-baseline）。
- **账本的统一形态 = 生态代谢理论（MTE）**：个体代谢率 `B = B₀ · M^(3/4) · e^(−Ea/kT)`（Brown 2004，scout 报告 §Q6）——体型、温度两个物理变量驱动代谢、寿命、繁殖延迟的整套缩放；3/4 指数有争议（Savage 2004）→ **做成可调参数，不硬编码**。温度场已有调制钩子（geology/cataclysm 的季节与尘埃项），MTE 落地后"温度带 = 代谢带 = 多样性带"免费获得。营养级传递效率 ~10%（Lindeman 1942）同样做参数——能量塔天然限制顶级捕食者密度，防"无限食物链"的多样性假象。
- **熵记账约定**：一切能量转换效率 <1 写成统一约定（每个转换都有废热去向）——文明层继承同一物理感（scout 报告 §Q6 建议 5）。
- **信息操作成本**：存储（记忆/知识占用的维持代谢）、复制（生殖时基因组复制的错误率与成本、文化传授的成本与保真度）、传输（信号距离/带宽）。现实规律接入点：香农容量（信道越好 → 保真越高 → 但维持信道有成本）；知识保真度=信道容量（Kirby 框架，scout 报告 §Q4）；信息存量指标用 Adami 式定义（序列中存储的关于环境的信息，scout 报告 §Q6）。现有 `image`（声誉）与 `sig/pref/tol`（生殖隔离信号）是这层的两个雏形，泛化为"社会信息状态"。

### 2.3 智能层：可演化的微脑

**为什么**：智能必须"可以出现"而非"一定出现"——唯一合法的设计是把智能做成**有真实能量价格的表现型**，让自然选择替我们决定要不要。

设计要点：
1. **基底**：极小循环网络（初始 ≤16 节点；节点数本身是基因座，经由重复突变增长——沿用 §2.1-A 的同一机制，脑不特殊）。激活函数走 `aether-libm`（黄金样本已有，`core/crates/aether-libm/tests/golden.rs`）。输出接口 = 通用效应器（期望速度/转向/咬合/发出信号/拾取放置），输入 = 感知向量（邻居摘要、资源梯度、内部状态）。
2. **grandfather 编译**：六祖先 kind 的现有 FSM 各编译成一个**参考网络**（等价参数化），初始六物种的脑 = 参考网络 + 微噪声。这避免了两难：不推翻现有生态（101+ 测试与 checksum 可控），又让行为从第一天起就落在可突变空间里（消灭 C11）。〔待确认：接受"统计等价"验收而非位精确等价，见 §7-Q3〕
3. **学习的最低阶梯从趋化开始**：第一级认知不是脉冲网络而是"慢变内部变量 + 时间差分"（E. coli 受体甲基化式：当前感受 − 近期基线 = 免费的时间差分器；Segall/Block/Berg 1986，scout 报告 §Q3 建议 3）——与现有感知半径机制直接兼容，几行代码即可落地；在此之上叠 Hebbian 资格迹与能量奖励（奖励 = 能量变化率，TD(0) 同构于趋化时间比较）。**不引入反向传播/梯度下降**（学习率调度带来跨平台浮点地狱，且生物上也不对）。
4. **成本三连（防"免费大脑"）**：`brain_cost = c_per_neuron × 节点数 + c_spike × 脉冲流量`——Herculano-Houzel 2011 证实跨物种每神经元能量预算近似恒定（scout 报告 §Q3），工程上脑成本 = 常数 × 神经元数；感知成本 ∝ 感官带宽；**突触更新按次扣能量**（Niven & Laughlin 2008 的能量压力论——免费学习会让最优学习策略统治一切、多样性平台化）。聪明必须按月付费——这就是"智能可以出现但不必然出现"的全部机制。
5. **实现参考**：NEAT 体量 ~2K SLoC 级；Rust 生态唯一活跃库 radiate 作阅读材料，**自研进 `aether-brain` crate**——RNG 全换 SimRng、激活函数走 aether-libm、剔除 thread_rng（scout 报告 §Q3 建议 4；确定性可控性优先于依赖现成库）。rustneat 等 8 年未更新的 crate 勿引入。
6. **明确不做**：不预设"智力测验"、不设"智能阈值事件"、不给大脑任何超出效应器接口的特权、不做脑可视化（观察层冻结）。

### 2.4 文化/技术层：知识作为可传播可积累可失传的载体

**为什么**：人类路线（石器 → AI）的核心引擎不是个体智能而是**累积文化**——知识在个体间高保真传播、跨代积累、且会失传。这是比脑更重要的文明前提。

- **知识 token**：开放结构的技能/信息单元（向量编码，无枚举的"科技列表"——铁律 1）。属性：习得成本、使用成本、复现收益、**复制保真度**（每次传授带保真度参数，受教-授双方的社会信息基因调制）、失传（载体死亡/使用率衰减）。
- **两个参数统治全部现象**：个体学习成本 `c` >0、传播保真度 `f` <1（scout 报告 §Q4）——Rogers 悖论（社会学习入侵种群却不提高平均适应度）、累积文化（创新率 ∝ 社会性 × 保真度 × 方差，Muthukrishna & Henrich 2016）、塔斯马尼亚式技术失传（有效群体跌破阈值 → 复杂技能衰减，Henrich 2004；Vaesen 2016 提醒人口规模非唯一轴 → 保真度做补充轴）全部是 `(c, f, N)` 的涌现输出。**让 f 依赖"教学行为/语言复杂度"是否演化出来**——语言与教学因此获得真实回报，不需要任何解锁脚本。
- **传输偏见三通道**（Boyd & Richerson 框架）：content / conformist / prestige bias 并存、全走 SimRng——只有从众通道会单一文化锁死（scout 报告 §Q4 已知坑）。
- **语言不硬编码**：先有"示范-模仿"动作通道；当需要向同伴描述未见对象时，iterated learning + 传播瓶颈 + 压缩压力 → 组合结构自动涌现（Kirby 2008/2015，scout 报告 §Q4——可复制的最小实验设计）。
- **创新算子**：token 重组 + 低概率变异（复用 §2.1 的突变机制——技术演化与生物演化共享算子，符合文化演化的"广义达尔文主义"）。创新三来源（偶然/重组/增量改进）全部可编码（scout 报告 §Q4）。
- **技术 = 生态位构造**：token 的最高级效果是**修改环境**（食物缓存、结构、土壤改良——mineral_field 已是最原始的先例，`ecology.rs:2758-2800`）。没有科技树：一种"技术"就是环境状态的一个持久改变 + 生成它的 token。"农业"将是"某 clade 的 token 使某植物类型的适合度场偏向自己"的涌现描述——scout 报告 §Q4 的 Bowles & Choi 2013 先例表明：农业式革命需要技术⇄制度互为前提（可防御的资源驻留结构 = 结构库），两者缺一不出现，这正是"潜力存在 + 达成与否由演化自己走"。
- **明确不做**：不写"文明阶段"、不设"科技解锁表"、不内置任何人类历史路径的复刻、不把"人口规模→复杂度"写成硬规则（Vaesen 2016 争议）。

### 2.5 文明层：Kardashev 式度量而非阶段脚本

- 文明不进 sim 的任何分支判断——它只是**涌现度量层（只读遥测）**：某 clade 捕获的能量通量占区域初级生产的比例（Kardashev 连续化，scout 报告 §Q5）、信息存量（存活知识项数 × 保真度，对接 Extended Kardashev 的信息轴）、组织复杂度（选择层级数/分工维度）、**Tainter 边际斜率**（新增复杂度的能量净收益做边际曲线——投资边际回报递减时群体自动分裂/简化，**崩溃是涌现不是脚本**）。这些是 §2.2 账本的免费副产品。
- **望远镜纪律**：以上指标绝不回写 sim 逻辑（scout 报告最高优先级建议 1；OEE 文献与"无剧本"方法论的唯一交集）。观察层冻结因此无冲突：这些统计走研究导出接口（headless CLI），不做新 overlay。
- **层级跃迁（大跃迁）作为扩展轴**：群体实体（拥有生死与繁殖，繁殖 = 单个体瓶颈 propagule——没有瓶颈的群体选择太弱，Godfrey-Smith 2011）+ 任务切换成本 + 代谢致突变"脏活"——三个文献验证过的最小触发条件（Goldsby 2012/2014，scout 报告 §Q2），全部可量化进能量系统；冲突调解器（germline 指定位/程序性死亡/亲缘识别）从简单机制起步、成本由账本支付。多细胞/真社会性因此成为**可涌现的数据结构而非 flag**；"选择层级数增长"本身当 OEE 里程碑检测（scout 报告 §Q2 建议 4）。放 Phase 39+ 扩展轴，31-38 验收后再细化。
- sim 内部唯一需要的是把 C3 的人口/能量上限撤掉，让"规模"重新成为可演化的变量。
- 历史记录走输出端：sim 只产出确定性事件日志（clade/灭绝/技术事件），叙事化在外环（Dwarf Fortress 的教训：日志叙事合法，硬编码事件系统不合法——它是"生成历史"而不是"生成历史的生成器"，scout 报告 §Q5）。

### 2.6 无限发展 × 有限算力：L0–L3 的回归路径

**为什么**：不设上限的世界在单线程 WebView 里只能靠"细节按需分配"活下来——这正是 v2.0 范式二的设计意图，本路线图让它以生态问题的形态回归。

- **何时引入**：Phase 38（多区域）是引入时机。判定信号：物种数×个体数的增长使 L2 全仿真超出单 tick 预算（先给测量门，见 §6-R3）。在 38 之前，L0/L1 以**小规模预研**存在（clade 级统计影：灭绝 clade 的化石已有 `SpeciesClade`；把"区域外 clade"降为丰度参数 + Lotka-Volterra 式聚合更新，观察/接触时按统计分布 refine 出 L2 个体——v2.0 §2.2 的 refine/coarsen 原样适用）。
- **L0 影子必须自身演化**：未观察/未接触区域的多样性与能量通量按确定性规则继续演化，否则观察范围外成为新颖性死区（scout 报告 §Q1 建议 3）；L0 聚合指标（物种数 × 生态位矩阵）直接当 OEE 仪表盘。
- **OEE 活动度监测**：Bedau 式"新增行为/形态/生态位类型的速率"作为研究导出；速率 → 0 说明**该调环境动态而不是调目标**（检测平台化而非治疗平台化，scout 报告 §Q1 建议 4）。
- **v2.0 三范式回归路径**：
  - 参考系树（`aether-coords`）：Phase 38 直接接线——每个区域一个 frame，f64 锚点，现有 GRID 76² 网格不变（格子不是限制世界大小的因素，区域数才是）。
  - 分层异步时间（`aether-clock`）：现有代码已有雏形——geology 每 10k tick、biochem 每 1k tick、分化每 60 tick 本来就是多时间尺度（`geology.rs:24`、`biochemistry.rs:28`），38 把它形式化为 per-region clock。
  - 观察驱动细节化：**降级为"接触驱动细节化"**——造物者不盯着的区域不 refine；但 clade 迁徙/战争/贸易接触到的区域必须 refine。确定性：refine 采样走 `(seed, region_id, epoch)` 派生的专用流，观察/接触路径写入存档（v2.0 §2.2 的既定方案）。
- **算力管理手段（预算不够时的答案，按序启用）**：表达成本自发抑制增长（经济学封顶，不是规则封顶——合法）、空间索引（31）、L0 影子（38）、多 wasm 模块懒加载（主模块 + 期次模块按世界实际达到的演化阶段分片加载——**这是"文明阶段"在工程上的唯一合法形态：加载策略在代码里，阶段本身在世界里**）、（最后手段）测量门触发的 L1 代理群档位。**不砍机制**。
- **工程前置（Phase 31 顺带）**：空间索引（uniform grid buckets）替换 `nearest` 的 O(n²) 扫描（C12）——这是无上限的前提工程，位精确等价可测（返回相同邻居）。

## 3. 分阶段路线图（Phase 31 起）

**总体纪律**（先读这段再看阶段）：
1. **每阶段可独立交付、可运行、可回滚**；禁止一次推翻重写。
2. **checksum 政策**：确定性 = 同 seed 同结果，永远不可破。基线**数值**分两类改动：①不改变任何动力学行为的重构（Phase 31-33 的目标）必须保持 `0x790184996f3acefd` 位精确不变；②引入真实新动力学的阶段（34 起）允许**一次、显式、有记录的 re-baseline**（旧值 → 新值写进阶段报告），此后再次锁定。〔待确认：re-baseline 审批流程见 §7-Q1〕
3. **测试基线**：101+ cargo 测试与 27 个 Node 套件每阶段全绿；新机制一律先加机制级注入测试（沿用 `kill_kind`/`inject_mineral`/`set_geo_plates` 模式）。
4. 每阶段「明确不做什么」与做什么是同等重要的交付物。
5. **OEE 四条件覆盖检查**是每阶段的验收子项：本阶段是否让条件①②③④中的哪一条更强、是否让任何一条变弱。

### Phase 31 · 核心泛化地基（Generalization Foundation）

- **目标**：消灭 C1 的全部硬编码 kind 分支——六物种的所有常数、行为入口、容量、互作对象全部从 `match` 降级为**数据表（KindDef registry）**；行为完全不变，checksum 位精确不变。
- **核心机制**：
  - `SpeciesKind = u16`（interning registry，字符串仅作名字）；`KindDef { 能量上限, 繁殖参数, 饮食标签, 感知/速度乘子, 容量, 状态机常量表, 祖先 FSM 指针 }`；六个 legacy kind 在启动时以数据定义。
  - 删除全部 `_ => unreachable!()`（`ecology.rs:924,933,1757,1775,1933,2094`）：未知 kind 走保守默认 KindDef。
  - `evolution/generation_fitness` 从 `[..;6]` 改为按 kind-id 有序 Vec（`ecology.rs:614-615`）。

## 4. 确定性纪律（Determinism Discipline）

**为什么**：可扩展表征/学习/文化全部是新增 RNG 消费者——没有纪律，"无上限"等于"不可复现"。现有工程已给出成熟模式（专用流 + 零 RNG 记账 + 基线无副作用），本节把它升格为协议。

1. **RNG 流森林**：主流/次流/鱼流/geology 流之外，新增层一律遵循——**要么零 RNG（纯记账，如 niche/cataclysm 先例），要么专用流（`seed ^ TAG` 派生，如 `GEO_RNG_TAG` 先例）**。文化层设 `CULTURE_RNG_TAG`；脑可塑性优先零 RNG（状态函数），确需探索噪声则设 `BRAIN_RNG_TAG`；区域 refine 设 `(seed, region_id, epoch)` 派生流。跨平台永远不碰 `rand`/`thread_rng`/时间。radiate 等外部参考库的 RNG 路径引入时必须全部替换（scout 报告 §Q3 已知坑）。
2. **draw 数固定原则**：每个代码路径的 draw 数是**状态的确定性函数**但不得是"平台相关的"或"HashMap 序的"。变长基因座是最大风险点：①突变遍历按座表 id 序；②每座固定 draw 数；③重复/缺失用**每基因组每代固定 1 个 roll 槽**（roll 值先与座数比较再决定是否作用于最后一个座）——任何基因组长度的突变成本恒定，杜绝"座数翻倍 → draw 数翻倍"的蝴蝶效应扩散。〔该协议在 Phase 32 实现前需写进 spec 并用黄金样本测试钉死〕
3. **浮点策略**：一切超越函数走 `aether-libm`（黄金样本制，`core/crates/aether-libm/tests/gold/`）；`js_hypot` 型位精确等价函数模式延续；新状态字段默认 f64（f32 仅限已有渲染/场层，如 grass/mineral_field）；禁 fast-math、禁目标平台依赖 libm。**NaN 纪律**：sim 内禁止产生 NaN（或统一 canonicalize）——WASM 3.0 已发布确定性 profile，但现阶段 NaN 位模式仍是非确定来源（scout 报告"额外发现"）。
4. **迭代序**：一切聚合遍历用 Vec 序（agent Vec = spawn 序为规范）；新增容器禁用 HashMap 迭代（`isolated_groups` 配 `isolated_order` 的既有先例，`ecology.rs:4188-4190`）。
5. **存档往返**：全状态捕获原则不变（`from_save_state` 不重跑 `init_grass/seed_life`，`ecology.rs:4174` 注释）；每 Phase 的 schema 走 additive + `#[serde(default)]` + 旧版回填默认为"无副作用的基线态"（`biochemistry.rs:28-36` 的 `FAST_BASELINE` 模式）；serde_json 必须保持 `float_roundtrip`（`Cargo.toml` 既有注释）。
6. **checksum 语义**：Phase 34 起切换到 v2（species_id u32 + 座哈希），迁移期两个 checksum 并行导出一个版本；**checksum 是回归测试锚，不是真理**——动力学变更允许 re-baseline，确定性（同 seed 同值）永不破。观察/接触路径（Phase 38 refine 采样）作为存档一部分，确保 refine 世界可复现。
7. **学习/文化的确定性**：资格迹更新 = 纯函数（输入、当前突触、dt）；token 复制的保真噪声走 `CULTURE_RNG_TAG` 流且每 token 每次复制固定 draw 数。

## 6. 风险（Top 3 + 次要）

**R1 · 泛化重构破坏位精确基线（Phase 31-33 的生命线）**
六 kind 的行为是 4500 行过程代码的交织；搬进数据表时任何 draw 序/求值序偏差都会打碎 `0x790184996f3acefd`，而对拍定位成本极高。缓解：每搬一个 match 就跑一次黄金回归；先搬无 RNG 的纯常数（die/biome_max_for），后搬含 RNG 的路径（random_genome/mutate/spawn）；空间索引替换 `nearest` 必须逐位等价或作为最后一步单独提交。

**R2 · 无上限 × 单线程性能的相遇时刻**
基因座无上限 + 脑节点无上限 + 文化 token 无上限，三个增长轴在 Android WebView 单线程上相遇：单 tick 成本曲线是增长的，而算力是平的。缓解按序：表达成本自发抑制增长（经济学封顶，不是规则封顶——合法）、空间索引（31）、L0 影子（38）、多模块懒加载、（最后手段）测量门触发的 L1 档位。**不砍机制**。学习状态内存膨胀的对策：每 agent 学习状态设硬上限（工程上限≠机制上限，scout 报告 §Q3 已知坑——上限只限存储密度，不限演化方向）。

**R3 · 涌现验证的可观测性真空（观察层冻结的副作用）**
机制是否真涌现只能靠 headless 研究导出（checksum、事件日志、OEE 活动度、统计 CSV）判断；若导出设计不足，团队将"盲飞"。缓解：每 Phase 的验收标准里显式列研究导出需求（已在各阶段"契约影响"写明）；测试即观察——机制级注入测试模式是主要的涌现验证手段；OEE 活动度仪表盘（38+）提供"平台化预警"。

次要：R4 kind 字符串在 C-ABI/渲染的兼容面（用派生 kind 名保持字符串兼容）；R5 SaveState 体积随 token/脑/座向量膨胀（紧凑编码 + 稀疏化，研究项）；R6 HERB 旧分化路径退役的团队情感成本（史迹保留在 git 历史与 oracle）；R7 伪 OEE 风险——无限随机噪声 ≠ 无限新颖性，活动度仪表必须区分"类型增长"与"个体扰动"（scout 报告 §Q1 Taylor 2016 批评）。

## 8. 附录

### 8.1 关键术语
- **KindDef / kind-id**：物种角色定义记录（数据表），取代编译期 `kind` 常量。
- **核心座 / ext 座**：Genome 中 17 个既有维度 / 开放基因座向量；ext 只能经重复突变产生。
- **重复突变（duplication）**：复制既有座为新座——"新基因从哪来"的现实规律答案。
- **kind 分叉（kind-fork）**：clade 距离超阈时铸造派生 KindDef——"新物种"作为纯数据事件。
- **能量账本（Energy Ledger）**：全 sim 唯一的摄入/损耗/废热/储存记账，MTE 幂律形态。
- **知识 token**：开放编码的可传播技能单元；无枚举科技表；`(c, f, N)` 三参数统治其动力学。
- **L0 统计影 / L2 全仿真**：v2.0 范式二的细节档位；本路线图以"接触驱动 refine"回归，且 L0 自身必须演化。
- **genesis 门控**：每 Phase 新机制的默认关闭开关——开启 = 世界纪元切换 + 一次 re-baseline。
- **参考网络（grandfather network）**：六祖先 FSM 编译出的等价脑——旧生态与新基因空间的接合面。
- **望远镜纪律**：一切涌现指标只遥测、绝不回写 sim 逻辑。
