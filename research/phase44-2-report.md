## 2. 五大长期模式

### 2.1 群体层繁荣且波动（选择层级 = 2 恒定）
组数 47-259（mean 139±55）、成员 126-486（mean 295）——群体形成/解体的完整周期振荡，群体层在百万尺度持续存在。

### 2.2 文化棘轮生效但知识长尾化
- tokens 线性增长（6728@1M）——发明+代际传承的稳定供给
- **bearers/tokens 比从 0.867 单调降到 0.029**——知识增长快于持有者增长：古老 token 逐渐失传，活知识集中在少数 bearer。文化棘轮「传新不传旧」——知识库膨胀，活跃知识集中（长尾化）。

### 2.3 认知成本份额持续上升
`cognition_share` 0.058 → 0.085（+47%）——三脑成本占总初级生产的比例百万尺度单调上升：脑驱动个体占比上升（authorities 83-415 波动中枢）或脑规模在选择下增长。**智能在被缓慢选择**。

### 2.4 稳定的诅咒：speciation = 0
**100 万 tick 零物种分化**（clades=0、OEE rate=0.00）。满容量稳态（每个物种顶格：herb 420 / scav 40 / omn 80 / fish→0 / deco 80）消除了分化的生态位空间——没有空缺生态位、没有灾变、没有未开发资源，物种形成没有驱动力。**稳定繁荣恰恰是物种多样化的敌人**（现实对应：热带雨林的高分化靠的是持续的小尺度干扰创造生态位）。

### 2.5 fish 灭绝事件（t≈137-143k）
fish 60 → 0 在 1.3 万 tick 内崩溃（auth 占比 68%→同步消失），能量正常（107-110，非饥饿）。候选死因：omn 满容量（80）的恒定捕食压力 × 脑驱动 fish 行为变化的交互。**fish 灭绝后 85 万 tick 无恢复**——abiogenesis 的 `ABIO_MIN_POP=8` 是全局门（世界活着就不触发），**物种级灭绝没有重启路径**（真实演化：物种灭绝不可逆，新物种只能靠分化——而 2.4 显示分化被稳定抑制）。

生态后果：五物种 → 四物种稳态（herb/scav/omn/deco），世界继续稳定运转——生态冗余吸收了单一灭绝。
