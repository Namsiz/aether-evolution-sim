## 1. 设计：为什么是「转移」而不是「增益」

Phase 54 的诚实发现：结构增草 → 初级生产 ↑ → HERB ↑ → 尸体供给稳 → DECO 根族稳态 → 漂变减速 → 80k 零分化。文化「提高产能」抑制「创造多样性」。

Phase 55 的机制假设：把结构效果改为**转移式**（net-zero dipole）——放置结构时，结构盘（Chebyshev 半径 3，49 格）按 `grass_mod × STRUCTURE_ENV_BOOST` 增/减乘子，**实际吸收量**（clamp 后的真实变化之和）原额反向分摊到外环（半径 3..5，72 格）。要点：

- **总量守恒**：场的均值在放置前后不变（except 环 clamp 截断，且截断只会缩小转移量；盘面饱和自限：盘钉在 MAX 吸收 0 就不再补偿）
- **符号保留**：正 token 盘面增草、负 token 盘面抑草——clade 的 token 符号差异 → 空间模式差异
- **clamp 自平衡**：`[0.5, 1.5]` 双向截断；吸收量来自盘的实际变化，避免 Phase 54 式单侧累积
- 衰减照旧 `0.998/tick`（半衰期 ≈ 350）——文化生态位必须持续维护
- 实现：`Ecology::structure_env_dipole(x, z, grass_mod)`（ecology.rs:3514），放置点调用（ecology.rs:6156 附近）；A/B 开关 `structure_env_off()` 不变

**A/B 与控制臂的 RNG 纪律**：偶极块是纯状态变换，零 RNG——ON/OFF 两臂 RNG 流完全一致，差异只来自乘子场。

## 3. 根因分析（为什么方向 1 注定失败）

1. **两层抑制**。近惰性扰动（Z 臂 BOOST=0.2，±1% 乘子）就已经错过 80k 窗口——OFF 的两次分叉（34.7k/41.8k）依赖一条具体的随机事件链，任何结构场扰动都会改写它。而真实镶嵌（R1，BOOST=2）的 200k 探针显示更强的系统性效应：OFF 叉 4 次、ON 零分叉（不是延迟）。
2. **是可达性，不是总量**。结构放置在 agent 家域 → 再生长集中到可达区域 → 即使净零守恒，可达生产 +2~4%、平均种群 +4% → HERB/DECO 更稳定 → 漂变减速。可测证据：200k 平均草量 ON 0.1939 vs OFF 0.1899；平均种群 544 vs 522。
3. **稳定化的两条路径都通向「不分叉」**：富庶盘 = 避难所（HERB 稳态 ↑）；饥荒核 = 但消费者重分布后同样抹平（X 臂 0 events）。正反符号都不支持分叉。
4. **上游干预不足**：草场是 HERB 的食物，DECO（分叉主体）吃尸体——结构效果要影响分化，必须更靠近 DECO 的适应度面（方向 2），或在 clade 间制造直接竞争（方向 3）。

## 5. 200k 探针（延迟还是死亡）

R1 标定 ON 与 OFF 各 200k（seed 20261102，`PHASE_TICKS=200000 PHASE_ARM_TAG=r1`）：

| 臂 | 分叉事件 | 终局 clades | 终局种群 | 备注 |
|---|---|---|---|---|
| OFF | **4**（t=34680、41760、125940、127980） | 5 | 352（处于低谷） | 未扰动世界持续分叉（125.9k/128.0k 又叉两次） |
| ON（R1） | **0** | 1 | 651 | DECO root 全程卡 80；env_mean ≡ 1.00000 |

**结论：不是延迟，是场级的系统性抑制**。200k 窗口里 OFF 叉 4 次而 ON 一次不叉。可解释的机制：结构放置在 agent 家域 → 再生长集中到「可达」区域 → 即使总量守恒，可达生产 +2~4%（200k 平均草量 ON 0.1939 vs OFF 0.1899）、平均种群 +4%（544 vs 522）→ HERB/DECO 更稳定 → 漂变减速 → MST 距离阈值永不越过。**Phase 54 的「农业降低多样性」在净零总量下依然成立：是集中度（可达性），不是总量。**
