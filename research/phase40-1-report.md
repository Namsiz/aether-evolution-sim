### 根因链（诊断实证）
```
PRED 灭绝（TROPHIC_EFF=0.10 下无法维持）
→ HERB 无天敌冲到满容量 420
→ Phase 4-A 密度刹车：threshold = 0.86 × (1+density).min(1.5) = 1.29-1.72 × max_energy
→ 永远不可达 → 零繁殖（diagnostic: generation 停在 1-4，平均年龄单调爬到 430）
→ 单代老龄化灭绝（hydration 0.93-0.97 充盈、能量 110-143 健康、草量 3564 充足——不是饥荒！）
→ 无尸体 → DECO 断粮 → 世界永久死寂
```

**机制缺陷本质**：密度刹车本意「满容量时降低繁殖率」，实际把繁殖概率压到 0——一个吸收态（absorbing state），种群一旦进入就不可逆地走向灭绝。

## 2. 修复

`REPRO_THRESHOLD_MAX = 0.90`（ecology.rs:390）：在所有 per-kind 覆盖后对阈值硬封顶。密度刹车保留（满容量时繁殖变稀有），但永不锁死——能量 ≥90% max 的个体永远能繁殖。

**试过但回退的方案**（均被观测否决）：
- mate_radius 11→25：低密度配对改善，但破坏高密度 seed 的稳定轨迹（seed2 反而崩溃）
- asexual 阈值全局 0.94→0.90：高密度繁殖爆发→能量抽干→崩溃
- 低密度 asexual 救急（<50 只时 0.90）：初始种群组装路径改变→稠密 seed 轨迹分叉→仍崩溃

**接受的现实**：阿利效应（低密度找不到配偶灭绝，seed 20261105/42 的 herb）是真实生态特征，不做工程干预。

## 6. 教训（写入记忆）

1. **密度刹车必须是软的**：任何把繁殖概率压到 0 的「刹车」都是吸收态——种群一旦进入就单向灭绝。刹车参数必须有可达上界。
2. **观测会暴露设计意图与实现后果的鸿沟**：Phase 4-A 设计时 PRED 存活（H 被压到 96-109，density≈0.25），刹车从未触发吸收态；PRED 灭绝后 H 满容量，刹车立刻变成死亡螺旋。机制在原始参数下正确，不代表在新参数下正确。
3. **修一个变量只动一个变量**：mate/asexual/阈值三案连调时轨迹全部分叉，无法归因；最终只保留阈值修复这一个改动。
4. **阿利效应是真实生态特征**：低密度灭绝不是 bug——工程干预会破坏高密度稳态，接受它。
