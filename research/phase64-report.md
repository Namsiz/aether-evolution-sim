# Phase 64 — M10 的 out-of-sample 复测（5 个全新 seed）

日期：2026-11-21
HEAD（起点）：`3626131`（Phase 63：`FORK_BUDGET_MIN 8 → 10`，第十八次 re-baseline）
性质：**预注册的 out-of-sample 复测**。Phase 63 的过线依据是 `Σ ext 17 → 10`，但收益几乎全部来自 seed 42（8 → 0），seed 20261102 反向 +3，其余三个 seed 是 −1 / 0 / −1；5-seed 池本身在 Phase 57–62 已反复使用，不构成 out-of-sample 证据（Phase 63 §10.1 明列）。本期唯一目的：用**从未参与任何 Phase 判定**的 5 个新 seed 检验 M10 的灭绝收益是否可复现。

> 本文件的第一版只包含 §1 预注册，在第一个 Phase 64 实验进程启动之前单独提交。运行期间 §1 不做任何修改；后续各节只追加。

## 1. 预注册（跑之前写死）

### 1.1 seed 选择规则（机械派生，不可挑）

**生成器**：日期编码 `2026_DD` = `20261100 + DD`，DD 从 `10` 起、到本期执行日 `2026-11-21` 的 `21` 止，**升序**枚举。

**过滤条件（按序应用）**：

1. 剔除 Phase 63 判定池：`20261102 / 42 / 20261109 / 20261105 / 20261107`；
2. 剔除 Phase 63 之前已用于任何判定的 seed：`20261103`（Phase 32 seed 池）、`20261113`（Phase 32 池 + Phase 57–62 的“非判定”补充，`tests/phase32_open_loci_test.rs:98`）；
3. 剔除仓库内**任何文件**已出现过的编码（`grep -rIl <seed> --exclude-dir=node_modules --exclude-dir=target --exclude-dir=.git` 命中即剔除）；
4. 取前 5 个。

这 5 个 seed 在**任何** Phase 报告中都没有出现过（含 Phase 57–63 的所有观测），因此对 M10 与 floor 8 都是 out-of-sample。**禁止在看到结果后追加、替换或删除 seed**；唯一例外是 §1.4 的退化替换规则。

### 1.2 两臂定义

编译默认为 Phase 63 转正后的 `FORK_BUDGET_MIN = 10`，所以两臂都必须显式设置，避免“默认 = 哪一臂”的歧义：

| 臂 | 环境变量 | 语义 |
|---|---|---|
| **OFF** | `PHASE_FORK_MIN=8` | Phase 49 旧链（8/11/15/20），即 Phase 63 被取代的默认世界 |
| **M10** | `PHASE_FORK_MIN=10` | Phase 63 新默认（grant floor 与父剩余 floor 同时为 10） |

`PHASE_FORK_MIN` 的 setter 同时设置 `fork_budget_min` 与 `fork_daughter_min`（`fork_budget_min_set`），与 Phase 63 的 M 臂语义逐位相同。其余开关全部编译默认（Phase 60 机制栈），`PHASE_BUDGET_GROWTH` 不设。

### 1.3 指标与判据（唯一判定）

指标定义沿用 Phase 63 §1.3：

- 分化 `spec` = `event_kind = 0` 的事件数（DECO 分叉）；
- 灭绝 `ext` = `event_kind ∈ {1, 2}` 的事件数（全族，含引擎竞争排除）；
- 反向 seed = `ext_M10(seed) > ext_off(seed)`。

| 判据 | 门槛（写死） | 说明 |
|---|---|---|
| **P1 分化不显著下降** | `Σ_M10(spec) ≥ 0.90 × Σ_off(spec)` | 相对门槛，不设绝对下限 |
| **P2 灭绝相对下降** | `Σ_M10(ext) ≤ 0.75 × Σ_off(ext)` **且** 反向 seed ≤ **2 / 5** | **本期从 Phase 63 的「绝对 ≤ 12」改为「OFF 的 75 %」**：新 seed 池的 OFF 基数未知，绝对值没有可比性；0.75 与 Phase 63 的实际 Q（10 / 17 = 0.588）同向、但明显更宽松，是对「收益可复现」的最低要求 |

两条判据**必须同时满足**才算通过；不接受事后的第三条“综合判断”。

### 1.4 退化替换规则（写死）

某 seed 判为**不可测**，当且仅当：OFF 与 M10 两臂在 200k 内 `spec + ext = 0`（世界没有发生任何分叉，M10 无从起作用）。

替换：从 §1.1 的生成器继续升序取下一个未被任何文件引用的编码（`DD = 22, 23, ...`），**最多替换 2 个**；替换的 seed 与原 seed 都要在报告中列出。若可测 seed < 5 → **inconclusive**：默认保持 M10、不 re-baseline、不据此否定机制。

### 1.5 决策表（写死）

| # | 结果 | 决策 |
|---|---|---|
| 1 | P1 过 **且** P2 过 | **M10 保持默认**；**不 re-baseline**（锚点不变）；报告把 5 新 seed + Phase 63 的 5 seed 合并为 10-seed 总表，作为强化证据 |
| 2 | P1 过 **且** P2 败 | **回退 `FORK_BUDGET_MIN = 8`**（**第十九次 re-baseline**，全锚点更新）；M10 保留为 `PHASE_FORK_MIN=10` 环境臂；结论写「M10 的灭绝收益不可复现」 |
| 3 | P1 败（无论 P2） | **回退 `FORK_BUDGET_MIN = 8`**（第十九次 re-baseline，全锚点更新）；结论写「M10 的分化代价在 out-of-sample 上越界」 |
| 4 | 可测 seed < 5 | inconclusive：默认保持 M10、不 re-baseline、不否定机制 |

第 2 条的理由写死：M10 在 Phase 63 转正的**唯一**依据是灭绝收益（分化是 −6 %，本身没有独立价值）；若该收益在全新 seed 上不可复现，M10 就失去了默认资格，即使它在分化上无害。保留代码路径（env 臂）以备 Phase 65 在更大 seed 池上再测。

### 1.6 执行协议

- release 二进制；每臂独立进程；`PHASE_SEED` / `PHASE_TICKS=200000` / `PHASE_FORK_MIN` / `PHASE_ARM_TAG=p64`；并发 4（8 核，内存 14 GB）。
- 单二进制：`cargo test --release --test clade_fate_observatory --no-run` 的产物，10 个臂只改环境变量、不重新编译。
- 产物落 `/tmp/p64/*.log` 与 `/tmp/clade_{fate,tree,culture,life}_*_p64*.csv`；另一臂的 CSV 用 `PHASE_ARM_TAG` 区分；报告成文后删除全部临时文件。
- **确定性自检（停止规则，不是结论）**：以 `PHASE_FORK_MIN=8` 跑 seed `20261102` @200k，必须复现 Phase 63 的 OFF 计数 **9 分化 / 4 灭绝**。任何偏差先查二进制、env 与开关状态，**不得据此计算任何结论**。
