## 1. 预注册（跑之前写死）

### 1.1 Phase 66 的负结果与 44.00 尖峰（为什么需要 R3）

Phase 66 的 5-seed 200k 确证（`research/phase66-report.md` §4）：

| 判据 | OFF | R1（REF 300 / MAX 320） | 结果 |
|---|---|---|---|
| 分化 `Σ spec` | 35 | 35 | P1 过（零和） |
| 灭绝 `Σ ext` | 13 | 16（+23 %） | **P2 败** |
| 派生支系 miss 总量 | 5 291 607 | 3 097 653（−41.5 %） | P3a 败（门槛 −50 %） |
| miss/clade-tick | 1398 | 868（−38 %） | 报告项 |
| `beyond_radius` 份额 | 67.6 % | 46.2 % | 机制咬到 |
| `filtered` 份额 | 7.2 % | 25.9 % | 半径不再是主约束 |

两条必须同时记住的事实：

1. **R1 不是没作用，而是作用过头**：它把「差一点」和「差很多」一起捞进搜索半径，`radius_only_finds` 达 1 962 296 次；出生/死亡只动了 +0.8 % / +0.6 %，但容量闸拒绝上升 4.6–5.1 %。读法是「成配提前 → 更快撞容量闸 → 更快耗散」，与 Phase 62 §3.2 的「容量饥饿是主因」一致。
2. **44.00 尖峰未被检验**：OFF 臂逐 clade 的 `min_ready_dist` 几乎都是 44.00，即同区域存在可育同族、距离恰好落在 legacy 上限（44）之外。R1 的 300–320 半径对这个尖峰不是最小干预；一个 80–120 的小地板是不同设计，Phase 66 明确未测（§5.2）。

**本期的科学问题**：如果只把搜索半径从 44 扩到「近邻」范围（80–120），能否救回 44.00 尖峰那一批配偶，同时不碰 274 均值的远距离长尾，从而在不抬高灭绝的前提下改善招募？

### 1.2 R3 机制（语义写死）

R3 是 R1 的**参数化变体**：同一密度律、同一作用域、同一 region 闸，只改量级，并加一个 80 的下限。

| 项 | 值 |
|---|---|
| 编译默认 | `MATE_FLOOR_ON = false`（臂旋钮 `mate_radius_arm = 0`） |
| 作用对象 | 仅 `kind_def(kind).parent_kind.is_some()`（派生 kind）；FISH / 根 kind / 六族祖先完全不变 |
| 密度量 | `n = region_count(kind, a_region)`（同 tag 的活体，含母亲；下限 1） |
| 地板 | `floor = clamp(R3_REF × sqrt(N_REF / n), R3_MIN, R3_MAX)`，`N_REF = 4` |
| 常量 | `R3_REF = 80`、`R3_MIN = 80`、`R3_MAX = 120` |
| 半径 | `radius = max(legacy, floor)`；`legacy = 11 × (1 + (1 − d) × 3)`（Phase 42.1 原式），FISH 仍 60 |
| 上限 | **120 硬顶**（Phase 66 R1 是 320） |

按此式算出的地板：

| n（同区域同 kind 人口） | 1 | 2 | 3 | 4 | 5 | 8 | 12 |
|---|---|---|---|---|---|---|---|
| R3 | 120（截） | 113.1 | 92.4 | 80 | 80（下限） | 80（下限） | 80（下限） |
| R1（对照） | 320（截） | 320（截） | 320（截） | 300 | 268 | 212 | 173 |

**为什么是这个形状**（写死论证）：

- **密度律沿用 R1**：R1 的公式已被 200k 实测咬到（`beyond_radius` 67.6→46.2 %），本期只改量级与下限，不引入第二个自由度。这样 R1 vs R3 的差异可归因到「半径大小」，而不是「换了一套密度语义」。
- **下限 80**：44.00 的尖峰在 4 人以上的 deme 也必须被覆盖；若只靠 `80 × sqrt(4/n)`，n≥5 时地板会跌到 71.6 以下，尖峰重新落到半径外。故 `R3_MIN = 80`。下限仍小于 120 硬顶。
- **上限 120**：`beyond_radius` 所需距离均值 274.2；120 只覆盖其近端，不碰长尾。120 同时是任务给出的硬顶。
- **不做「固定 120」**：固定值会让 8 人 deme 也搜 120，等于把 R1 的「按密度」自由度删掉；下限 + 反平方根保留稀疏 deme 更宽、密集 deme 收窄的方向，且所有派生 deme 至少 80。

**边界（写死）**：

| 情况 | 处理 |
|---|---|
| `floor ≤ legacy` | 逐位退回 legacy；D0 不记 boost |
| 根 kind / FISH | 永不进入地板分支 |
| 支系只有母亲 1 只 | `n = 1` → 120 |
| 半径变大但配偶在别的 region tag | filter 仍拒绝；`region_isolation` 语义不变 |
| 半径内最近的配偶 | 仍是 `nearest` 的几何最近者，**不是**随机选择；零 RNG |
| 出生位置 | 不变（母方 home + jitter）；机制只改搜索上界 |
| 存档 | 不入档（与 `fork_budget_min` / `grace_ticks` 同契约）；读档回编译默认 OFF |
| 守恒 | 不改任何预算/能量/槽位；`family total` 恒等式不受影响 |

### 1.6 指标定义（P3 修正 Phase 66 的方法论）

- 分化 `spec` = `event_kind = 0` 的事件数；灭绝 `ext` = `event_kind ∈ {1, 2}` 的事件数（全族；DECO 单列）。
- **派生支系** = `clade_life` 中 `root_kind = DECO ∧ clade_id != 0` 的行（机制作用域）。
- **clade-ticks（写死分母）**：对每个派生支系，`life_ticks = (extinction_tick.unwrap_or(200000) − first_tick)`；`Σ clade-ticks` 是该 seed 所有派生支系之和。该口径与 Phase 66 §4.1 的 663 896 / 999 895 等数字逐位一致（已在 p66 CSV 上复算确认）。
- **P3 主指标（修正）**：`R = Σ_derived_misses / Σ_derived_clade_ticks`（单位：miss / tick；报告乘 1000 显示为 miss/ktick）。**不再用 miss 总量**：Phase 66 的 P3a 总量在臂间 clade 数不同时不可比（R1 的 miss/clade-tick −38 %，总量只 −41.5 %）。
- **P3 分桶**：同一分母下分别报告 `no_kin / other_region / beyond_radius / filtered / other` 的率。
- **P3b 报告（不判定）**：`miss/birth = Σ_derived_misses / Σ_derived_births`。
- **D0 作用力**：`radius_boost_searches`（地板把半径抬高的搜索次数）与 `radius_only_finds`（在 legacy 半径外、只靠地板找到配偶的次数），两者都 > 0 才算咬到；另报告 `radius_only_find_dist_mean`（被救配偶的平均距离，检验是否只发生在 120 以内）。
- 守恒 = 末态每族 `Σ kind_budget`（`[budget]` 的 parent 链聚合）。
- 区域交互 = `region_cap_blocks` / `deaths_off_region` / 每 clade 的 `region_peak`（报告，不参与判定）。

### 2.3 P3 口径与作用域修正（执行中发现，写进报告）

预注册 §1.6 为保持与 Phase 66 可比，把派生支系写成 `root_kind = DECO ∧ clade_id != 0`。这个代理在本期 seed 池上失效：`20261201` 的 **DECO 根 clade 物化为 id 1**（pred 根先占了 id 0），于是「根」被算进了「派生」；而地板从不对根 kind 生效。修正方式：

- 判据、门槛、分母定义不变；
- 作用域改为「clade 的 kind 有 `parent_kind`」（`tests/clade_fate_observatory.rs:559-572`），两臂对称重算；
- 两种口径都列出，见下。

| 口径 | OFF miss / clade-ticks / 率 | R3 miss / clade-ticks / 率 | 比值 |
|---|---|---|---|
| 旧代理 `clade_id != 0` | 3 582 830 / 2 469 756 / **1450.7** | 4 929 086 / 4 041 270 / **1219.7** | **0.841** |
| **修正后（派生 kind）** | **3 582 693 / 2 456 196 / 1458.6** | **4 631 175 / 3 843 370 / 1205.0** | **0.826** |

修正只影响 `20261201` 的 OFF/R3 两行：R3 侧剔除根 DECO 的 297 911 次 miss 与 197 900 clade-ticks，OFF 侧相应为 137 次 miss 与 13 560 clade-ticks。结论不变：两种口径都远高于 0.50 的门槛。

**残余污染（诚实边界）**：`clade_life` 的行键是 `(clade_id, root_kind)`，同一 clade 行里若混入根 DECO kind 的 agent，其 miss 仍会记到派生行。直接证据：R3 下 44 个有 `beyond_radius` 的派生 clade 里仍有 **8 个** `min_ready_dist = 44.00`，而真正的派生 kind 搜索半径恒 ≥ 80，不可能记录 44。该污染在 OFF 臂同样存在、且量级不足以跨越 0.826 vs 0.50 的差距；Phase 68 若要更纯的作用域，应在 `clade_life` 行里增加 `kind_id` 维度。

## 5. 决策

**不通过 → 默认保持 OFF；不 re-baseline（第二十次 re-baseline 没有发生）。**

依据（按 §1.8 决策表）：

1. **P2 败**（25 > 15.75，反向 3/5）→ 第 4 行：招募改善未转化为存活，OFF。
2. **P3 也败**（0.826 > 0.50）→ 即使 P2 被放宽，主指标也未达标。
3. P1 过（44 ≥ 27.9）与 D0 过（1036 万 / 72.7 万 / 61.67）不能补偿 P2/P3；P1 是下限，不是目标。

### 5.1 与 Phase 66 R1 的对照：同一条通道的两种剂量

| 维度 | OFF | R1（Phase 66） | R3（本期） |
|---|---|---|---|
| 半径上界 | 44 | 320 | **120** |
| 分化 | 35 | 35（0 %） | **44（+42 %）** |
| 灭绝 | 13 | 16（+23 %） | **25（+19 %）** |
| `beyond_radius` 份额/率 | 67.6 % | 46.2 % | 率 −24.2 % |
| 半径外成配 | 0 | 1 962 296 | **727 181** |
| 平均补捞距离 | — | 未记录 | **61.67** |
| 容量拒绝 | 基准 | +5 % | **+55～62 %** |

R3 是 R1 的「小剂量」版本：它只捞近邻（平均 61.7，硬顶 120），没有碰 274 均值的远距离长尾；它确实消掉了 44.00 尖峰，miss 率也降了 17.4 %——但**灭绝仍然上升 19 %**，且容量闸拒绝上升 55–62 %（R1 只有 5 %，因为 R1 的成配增量被更大的 clade 数稀释）。

**读法**：R1 的失败曾被归因于「半径太大、把差很多也捞进来」；R3 把这个解释证伪了。即使只捞「只差一点点」的近邻，支系仍会更快撞上容量闸。**择偶半径不是招募/存活的独立杠杆；它只是把容量闸的拒绝提前。** 这与 Phase 62/65 的定因链一致，现在有了最小半径的直接证据。

### 5.2 没有证明什么（诚实边界）

- **没有证明「任何择偶半径设计都有害」**：只测了 80–120 的小地板与 150–320 的大地板；「固定 120、无密度律」与「80 上限」未测。但两者都被本期的剂量-反应覆盖在 80–120 区间内，且 R3 已是该区间的下限形态。
- **没有证明 44.00 尖峰不是真约束**：它确实被 R3 消掉了；我们证明的是「消掉它不足以改善存活」，不是「它无关」。
- **P1 的 +42 % 不是「R3 促进分化」的定论**：5 seed 里 2 个方向为负（03、05），合计 +13 由 01/04 两个 seed 主导。它是「周转加速」的伴生现象，不是稳定的分化增益。
- **残余 44.00 污染**（§2.3）：8/44 的 R3 clade 仍记录 44.00，来源是 `(clade_id, root_kind)` 行内混入根 kind agent；P3 的 0.826 对该污染稳健，但更纯的作用域需要 `kind_id` 维度。
- **P2 门槛的严格性**：0.75 × OFF 要求 −25 %；R3 是 +19 %。结论不依赖门槛（放宽到「不差于 OFF」也败），但「R3 是否比 R1 更不坏」不能从 P2 的绝对值直接比较（两期 OFF 基线不同）。

## 11. Phase 68 遗留

1. **择偶半径方向应关闭**：R1（320）、R3（120）两期、三种剂量都败在存活。不要再用「更小的半径」重试；若还要动择偶，必须与容量侧同时设计（否则只是把拒绝提前）。
2. **44.00 尖峰已解释并消掉，存活没变好**：说明「最近可育距离」不是存活的约束。Phase 68 应把仪器移到「成配 → 出生 → region_cap 拒绝 → 死亡」的三段漏斗，按 clade 记录每一段，回答「为什么更多成配反而更多灭绝」。
3. **P3 作用域缺陷**：`clade_id != 0` 不是派生支系的可靠代理（DECO 根可能物化为 id 1）。下期预注册直接写「kind 有 `parent_kind`」，并在 `clade_life` 行加 `kind_id` 维度，消除 `(clade_id, root_kind)` 的根 kind 混记。残余 8/44 的 44.00 就是证据。
4. **总量指标彻底退役**：R3 的派生 miss 总量 +29 %、率 −17 %、durations +56 %；任何用总量的 A/B 都会得出相反结论。下期主指标固定为 miss/clade-tick，并同时报 miss/birth（本期 507.8 → 417.2，−17.8 %）。
5. **P2 门槛与非劣性**：0.75 × OFF 要求 −25 %，对「期望中立」的机制过严。若下期候选的意图是「不更坏」，应在预注册里单列非劣性门（如 ≤1.10 × OFF），不要事后放宽本期的 0.75。
6. **R3 的周转信号**：+42 % 分化、+19 % 灭绝、live clades 16→25。这是「更多支系、更快周转」的真实信号；如果目标是多样性而非存活，值得单独预注册（以 clade 持续期/灭绝风险为主指标），但不要把它包装成本期的招募收益。
