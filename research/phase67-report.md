## 1. 预注册（跑之前写死）

### 1.1 Phase 66 的负结果与 44.00 尖峰（为什么需要 R3）

Phase 66 的 5-seed 200k 确证（`research/phase66-report.md` §4）：

| 判据 | OFF | R1（REF 300 / MAX 320） | 结果 |
|---|---|---|---|
| 分化 `Σ spec` | 35 | 35 | P1 过（零和） |
| 灭绝 `Σ ext` | 13 | 16（+23 %） | **P2 败** |
| 派生支系 miss 总量 | 5 291 607 | 3 097 653（−41.5 %） | P3a 败（门槛 −50 %） |
| miss/clade-tick | 1398 | 868（−38 %） | 报告项 |
| `beyond_radius` 份额 | 67.6 % | 46.2 % | 机制咬到 |
| `filtered` 份额 | 7.2 % | 25.9 % | 半径不再是主约束 |

两条必须同时记住的事实：

1. **R1 不是没作用，而是作用过头**：它把「差一点」和「差很多」一起捞进搜索半径，`radius_only_finds` 达 1 962 296 次；出生/死亡只动了 +0.8 % / +0.6 %，但容量闸拒绝上升 4.6–5.1 %。读法是「成配提前 → 更快撞容量闸 → 更快耗散」，与 Phase 62 §3.2 的「容量饥饿是主因」一致。
2. **44.00 尖峰未被检验**：OFF 臂逐 clade 的 `min_ready_dist` 几乎都是 44.00，即同区域存在可育同族、距离恰好落在 legacy 上限（44）之外。R1 的 300–320 半径对这个尖峰不是最小干预；一个 80–120 的小地板是不同设计，Phase 66 明确未测（§5.2）。

**本期的科学问题**：如果只把搜索半径从 44 扩到「近邻」范围（80–120），能否救回 44.00 尖峰那一批配偶，同时不碰 274 均值的远距离长尾，从而在不抬高灭绝的前提下改善招募？

### 1.2 R3 机制（语义写死）

R3 是 R1 的**参数化变体**：同一密度律、同一作用域、同一 region 闸，只改量级，并加一个 80 的下限。

| 项 | 值 |
|---|---|
| 编译默认 | `MATE_FLOOR_ON = false`（臂旋钮 `mate_radius_arm = 0`） |
| 作用对象 | 仅 `kind_def(kind).parent_kind.is_some()`（派生 kind）；FISH / 根 kind / 六族祖先完全不变 |
| 密度量 | `n = region_count(kind, a_region)`（同 tag 的活体，含母亲；下限 1） |
| 地板 | `floor = clamp(R3_REF × sqrt(N_REF / n), R3_MIN, R3_MAX)`，`N_REF = 4` |
| 常量 | `R3_REF = 80`、`R3_MIN = 80`、`R3_MAX = 120` |
| 半径 | `radius = max(legacy, floor)`；`legacy = 11 × (1 + (1 − d) × 3)`（Phase 42.1 原式），FISH 仍 60 |
| 上限 | **120 硬顶**（Phase 66 R1 是 320） |

按此式算出的地板：

| n（同区域同 kind 人口） | 1 | 2 | 3 | 4 | 5 | 8 | 12 |
|---|---|---|---|---|---|---|---|
| R3 | 120（截） | 113.1 | 92.4 | 80 | 80（下限） | 80（下限） | 80（下限） |
| R1（对照） | 320（截） | 320（截） | 320（截） | 300 | 268 | 212 | 173 |

**为什么是这个形状**（写死论证）：

- **密度律沿用 R1**：R1 的公式已被 200k 实测咬到（`beyond_radius` 67.6→46.2 %），本期只改量级与下限，不引入第二个自由度。这样 R1 vs R3 的差异可归因到「半径大小」，而不是「换了一套密度语义」。
- **下限 80**：44.00 的尖峰在 4 人以上的 deme 也必须被覆盖；若只靠 `80 × sqrt(4/n)`，n≥5 时地板会跌到 71.6 以下，尖峰重新落到半径外。故 `R3_MIN = 80`。下限仍小于 120 硬顶。
- **上限 120**：`beyond_radius` 所需距离均值 274.2；120 只覆盖其近端，不碰长尾。120 同时是任务给出的硬顶。
- **不做「固定 120」**：固定值会让 8 人 deme 也搜 120，等于把 R1 的「按密度」自由度删掉；下限 + 反平方根保留稀疏 deme 更宽、密集 deme 收窄的方向，且所有派生 deme 至少 80。

**边界（写死）**：

| 情况 | 处理 |
|---|---|
| `floor ≤ legacy` | 逐位退回 legacy；D0 不记 boost |
| 根 kind / FISH | 永不进入地板分支 |
| 支系只有母亲 1 只 | `n = 1` → 120 |
| 半径变大但配偶在别的 region tag | filter 仍拒绝；`region_isolation` 语义不变 |
| 半径内最近的配偶 | 仍是 `nearest` 的几何最近者，**不是**随机选择；零 RNG |
| 出生位置 | 不变（母方 home + jitter）；机制只改搜索上界 |
| 存档 | 不入档（与 `fork_budget_min` / `grace_ticks` 同契约）；读档回编译默认 OFF |
| 守恒 | 不改任何预算/能量/槽位；`family total` 恒等式不受影响 |

### 1.3 与 R1 的对照论证（为什么不是重复失败）

| 维度 | R1（Phase 66） | R3（本期） |
|---|---|---|
| 半径 | 150–320 | 80–120 |
| 覆盖的配偶距离 | 44–320（含 274 均值长尾的大部） | 44–120（只覆盖近端） |
| `beyond_radius` 设计目标 | 把桶压到 46.2 % | 只压「44 附近」那一小段；长尾仍是 `beyond_radius` |
| 预期成配增量 | 196 万次半径外成配 | 应显著更小（P3 会量化） |

R3 的失败不会自动否定 R1 的结论；R3 的成功也不会自动让 R1 转正。两期各自独立预注册。

### 1.6 指标定义（P3 修正 Phase 66 的方法论）

- 分化 `spec` = `event_kind = 0` 的事件数；灭绝 `ext` = `event_kind ∈ {1, 2}` 的事件数（全族；DECO 单列）。
- **派生支系** = `clade_life` 中 `root_kind = DECO ∧ clade_id != 0` 的行（机制作用域）。
- **clade-ticks（写死分母）**：对每个派生支系，`life_ticks = (extinction_tick.unwrap_or(200000) − first_tick)`；`Σ clade-ticks` 是该 seed 所有派生支系之和。该口径与 Phase 66 §4.1 的 663 896 / 999 895 等数字逐位一致（已在 p66 CSV 上复算确认）。
- **P3 主指标（修正）**：`R = Σ_derived_misses / Σ_derived_clade_ticks`（单位：miss / tick；报告乘 1000 显示为 miss/ktick）。**不再用 miss 总量**：Phase 66 的 P3a 总量在臂间 clade 数不同时不可比（R1 的 miss/clade-tick −38 %，总量只 −41.5 %）。
- **P3 分桶**：同一分母下分别报告 `no_kin / other_region / beyond_radius / filtered / other` 的率。
- **P3b 报告（不判定）**：`miss/birth = Σ_derived_misses / Σ_derived_births`。
- **D0 作用力**：`radius_boost_searches`（地板把半径抬高的搜索次数）与 `radius_only_finds`（在 legacy 半径外、只靠地板找到配偶的次数），两者都 > 0 才算咬到；另报告 `radius_only_find_dist_mean`（被救配偶的平均距离，检验是否只发生在 120 以内）。
- 守恒 = 末态每族 `Σ kind_budget`（`[budget]` 的 parent 链聚合）。
- 区域交互 = `region_cap_blocks` / `deaths_off_region` / 每 clade 的 `region_peak`（报告，不参与判定）。

### 1.7 判据（唯一判定，200k 5 seed × 2 臂）

| 判据 | 门槛（写死） | 说明 |
|---|---|---|
| **P1 分化** | `Σ_cand(spec) ≥ 0.90 × Σ_OFF(spec)` | 硬门；**先于 P2 判定**，灭绝收益不能补偿分化损失 |
| **P2 灭绝** | `Σ_cand(ext) ≤ 0.75 × Σ_OFF(ext)` **且** 反向 seed ≤ 2 / 5 | 反向 = `ext_cand(seed) > ext_OFF(seed)` |
| **P3 主指标** | `R_cand ≤ 0.50 × R_OFF` | 修正后的 miss/clade-tick 率；作用于机制作用域 |
| **D0 作用力** | `boost > 0` **且** `only_find > 0` **且** `only_find_dist_mean ≤ 120` | 防「仪器没咬到」与「半径越界」被写成机制有效/无效 |

P1、P2、P3 必须同时满足；D0 是必要条件。P3b（miss/birth）与分桶率只报告、不判定。

**可测性**：若 5 seed 的 `Σ_derived_clade_ticks = 0`（两臂都没有任何派生 DECO 支系），P3 不可测 → 决策表第 6 行。若某 seed 的 `Σ clade-ticks = 0`，该 seed 从 P3 的分母与分子中同时剔除并在报告中列出；P1/P2 仍用全部可测 seed。

### 1.9 退化替换与快筛规则（写死）

**退化**：某 seed 判为不可测，当且仅当 (i) OFF 与候选臂在 200k 内 `spec + ext = 0`，或 (ii) DECO 根（`clade_id = 0`）在两臂都于 `t < 10 000` 灭绝。替换按 `20261206 → 20261207` 升序，**最多 2 个**；替换 seed 与原 seed 都列出。若可测 seed < 5 → 决策表第 6 行。

**快筛**：本期**不设独立 80k 分化门**。Phase 66 的 3-seed 80k spec 门把 15→11 当成否证，而 200k 上同一机制是 35→35（§11.3 的教训）。执行协议改为：

1. 先跑 5 seed × 200k × 2 臂；
2. D0 与分桶从同一批 200k 日志读取（`[radius]` / `[mate]` / `[mate_rate]`）；
3. 不因中间结果提前停臂；不追加 seed。
