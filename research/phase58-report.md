### 1.1 死亡诊断器（临时，用完删除）

`tests/_tmp_phase58_death_diag.rs`（`#[ignore]`，只读观察，不写引擎状态）：每 tick 重建 **(kind, clade)** 人口学（数量/能量/年龄/寿命/区域/bbox/eff/最高能量/可育数/最近配对距离），按「上一次观测到的状态」给每个消失个体归类（`energy ≤ 5` → 饥饿，`age ≥ lifespan − 2` → 老龄，其余 other），每 50 tick 采样家域 bbox 内的分解场（均值/var/贴下界比例/贴上界比例/结构数），并在每个非物种形成事件上 dump：濒死 clade 的最后活体画像 + 最近 5k tick 死亡构成 + 5k 场史 + 同刻存活 clade 对照。

### 2.1 判据落点：`eff ≥ 0.96` 是生育硬闸

`reproduce()` 的 DECO 个性化阈值 = `0.96 × (2 − deco_efficiency)`（selective 模式，乘拥挤项 ≥1）。DECO 的 `max_energy = 100`，所以

- `eff ≥ 0.96` ⇒ 阈值 ≤ 1.0 ⇒ 能量闸可通过；
- `eff < 0.96` ⇒ 阈值 > 1.0 ⇒ **该个体永远无法达到**（能量被 `min(energy, max_energy)` 截顶）。

诊断器逐 tick 统计 `ready`（按阈值+repro cd+age>30 判定）：deco-C 在其 5 580 tick 的余生里 `ready ≡ 0`，而 **min_pair = 0.5–0.8**（同族个体紧贴在一起）——不是找不到配偶，是**生育闸门打不开**。这与 Phase 15/34 的「DECO_MUT_SCALE=5 大突变换出物种」互为代价：同一支大突变既能越过 0.25 的物种距离，也能把 eff 甩到 0.96 以下，造就一支出生即绝育的女儿支。

### 2.2 与 Phase 56 的对照：这些灭绝都不是结构压死的

- 事件 1、3、4 的判定与 denv 场无关（1、3 场是 1.0000；4 双臂逐 tick 同型）。
- 只有事件 2（seed 42）的场证据是「相关且方向合理」：其家域 5k 均值长期 1.02–1.07（加速分解 = 食物寿命更短），末期跌到 0.899；但**同域无贴边**——bbox 内贴下界/贴上界比例只有 0.00–0.01，说明结构在那里留下的是温和场（未钉死在 0.5/1.5）。同刻 DECO 根仍有 60 个体、deco-A 12 个体存活，说明是**支系级饥饿**而非区域灭绝。真正的死因链是「eff 0.56–0.78 的近绝育支系 + 食物收紧」：早段 starved 5k 只有 1–3，96k 后升到 7–9，births 从 11–14 掉到 5，人口 8→5→2→1。判为「竞争/饥荒为主，场为加速因素」。
- **没有任何一起灭绝发生在「贴边比例高」的家域**：事件 1/3/4 的家域 `denv_var` 是 ≤0.0004 / 0 / ≤0.005；事件 2 的 var 0.02–0.17 来自结构数量（其 bbox 内 273–875 个结构）而非贴边（lo/hi 比例 0.00–0.01）。Phase 56 的「结构压力会杀 clade」需要在场强最大（贴边）的区域才能验证，本期的事件样本不支持它。

### 3.1 判读：任务判据未通过 —— 「撞边界」不是普适机制

1. **0.6/1.4 不通过（0 events）**，0.4/1.6 也不通过（0 events）。所以「只要把乘子钉在边界上就会分化」**被证伪**：narrow 臂的盘面同样被钉在下界（0.6×），环带同样抬到 1.27×，`denv_var` 甚至比默认臂高 3.5 倍（0.049 vs 0.018），结果 DECO 满编、零分化。
2. **单边扰动也全部失败**：只抬天花板（0.5/1.6）和只降地板（0.4/1.5）各自都归零。这说明默认臂里**两侧边界都在起作用**（环带叠加确实会顶到 1.5；地板 0.5 与 0.4/0.6 是三种不同的食物寿命），工作点窄到 ±0.1 就不能偏。
3. **真正的判别变量是「DECO 是否被赶下 80 满编」**，六个臂无一例外：DECO 满编（80）⇒ 0 events；DECO 掉档（60/34/31）⇒ 2–6 events。这与 Phase 56/57 的判读一致（`deco=80 → 零分化`），但把因果说得更死：**场的作用是「把 DECO 从容量顶打下来」，而不是「制造方差」**。方差与结果没有单调关系：var 0.046–0.055 的三个臂分别是 0/0/6 events，而 var 最低（0.018）的默认臂是 3 events。
4. **符号垄断不是充分条件**：E 臂（0.4/1.5）保持正号垄断（2178/7）、D/wide/设计b 翻成全负号——分别对应满编与掉档两种结局，说明「正号粮仓」既不是必要条件也不是充分条件；Phase 57 的「符号垄断是必要成分」应改述为「符号垄断 = 默认轨迹在这条 basin 里的产物」。
5. **文化对边界高度敏感**：±0.1 的 clamp 改动在 10k 内就改掉了整条文化轨迹（wide/D/设计b 全负号，narrow/E 正号）。这不是「同一机制的不同强度」，是四条不同的世界线。

**结论（供 Phase 59 决策）**：Phase 56 的 `[0.5,1.5] + GAIN=20` 是一个**窄工作点**，不是普适机制；它比 OFF 臂好（3 vs 2 events），但四个相邻工作点全部**比 OFF 更差**（0 vs 2）。把这条机制写成「撞生理边界 ⇒ 分化」是不成立的；正确表述是「**在本模型的这组标定下，分解场把 DECO 打下 80 满编；一旦打下，物种形成就发生**」。

### 3.2 是否改默认？

**不改**。判据是 events ≥ 1，而 0.6/1.4 与 0.4/1.6 都是 0；默认 `0.5/1.5 + GAIN=20` 保持。因此本期**没有 re-baseline**，全部锚点不动（§6）。

## 4. 块 3：设计 b（放置取最高价值 token）A/B

同一 `clade_fate_observatory`，80k × seed 20261102 × DECO 场 ON，唯一差异是 `PHASE_PLACE_VALUE=on`：

| 臂 | 物种形成 | 灭绝 | clades@80k | DECO@80k | denv_var@80k | structs@80k | 结构符号 pos/neg | per-clade `frac_grass_positive` |
|---|---|---|---|---|---|---|---|---|
| 默认（`known_tokens[0]`） | 3（23.70k/39.54k/76.38k） | 1（81.96k，发生在 80k 之后） | 4 | 34 | 0.01800 | 1890 | 1809 / 81 | 0.115–0.489 |
| **设计 b（最高价值）** | **5**（33.90k/34.14k/38.46k/43.80k/49.02k） | 1（39.48k，deco-A） | 6 | 31 | 0.04629 | 1680 | **0 / 1680** | 全 0.000 |

**结论：物种形成数上升（5 ≥ 3），但「符号分化」失败——符号反而更单一。**

- 机制：`value_of` 从 0 起步（全平手）⇒ 平手取最小 id ⇒ 首次放置锁定最早注册的 token ⇒ `record_use` 只给这一枚加价值（正反馈）⇒ 价值榜被首枚 token 永久垄断。本 seed 下最早注册的 token 是负号，于是全场 1680 个结构全负号，`frac_grass_positive` 全部 0.000。
- 也就是说设计 b 把 Phase 57 的「发明先验锁死符号」换成了「注册顺序锁死符号」，**符号多样性没有变好**。它带来的分化增益来自另一条路：全负号 ⇒ 盘面是荒漠、环带是粮仓 ⇒ DECO 掉到 31（off-cap）⇒ 分化。
- 因此按任务约定：**A/B 数据交付，默认不变**（`token_placement_by_value = false`），不 re-baseline。若要真做「符号分化」，下一步要么让价值在符号之间有频变溢价（与「无预设语义」冲突，慎用），要么先修发明先验（见 §8）。

## 9. Phase 59 遗留

1. **默认机制其实是窄工作点**：`0.5/1.5 + GAIN=20` 是唯一通过点，四个 ±0.1 邻居全部 0 events 且比 OFF 更差。要么接受「这是标定而非定律」，要么换一个不依赖精确边界的机制（例如让对比度随区域的 DECO 承载历史自适应）。
2. **生育断崖 `eff = 0.96`** 是新发现的硬闸：`0.96 × (2 − eff) ≤ 1` 才可育。它让大突变换种自带 50% 的绝育风险（本期两起灭绝）。是否把阈值映射改成饱和式（例如 `0.96 × (1.5 − 0.5·eff)`）让 `eff∈[0.5,1.5]` 全区间可育、只改变难度，是一个需要 re-baseline 的设计决定。
3. **符号多样性仍无解**：发明先验（`vec[0] = 2·grass − 1`）与价值榜的正反馈（设计 b 的「注册顺序锁死」）都会把符号锁死。要检验「符号分化」必须先让符号成为**中性标记**，而 Phase 57 已证伪「奖励解耦」这条路。
4. **42 的饥饿事件**需要 field × 竞争 × 食物寿命的定量分解（本期只到「相关且方向合理」）。
5. **诊断器可产品化**：`min_pair` / `ready` / `eff` 三列是「sparse clade 死因」的直接判据，建议并入 `clade_fate_observatory` 的 per-clade dump（本期为省时用临时文件）。
