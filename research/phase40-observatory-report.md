## 2. 结果：三个世界的三种命运

### seed 20261102 —— 死亡螺旋，永久死寂

```
t=2000  PRED 灭绝
t=7000  herb/scav 灭绝（食物链底部断裂）
t=8000  omn/fish 灭绝
t=21000 deco 灭绝（最后一只分解者饿死）
t=21000 → 100000  种群 = 0，世界永久死寂（79,000 tick 无任何生命）
```

峰值：61 群体 / 183 成员（t=3000）；分化 3 次（deco→deco-A dist=0.363 等）。

### seed 20261105 —— 更快的死亡

```
t=2000  PRED 灭绝
t=5000  scav/omn/fish 灭绝
t=6000  herb 灭绝
t=9000  deco 灭绝
t=9000 → 100000  种群 = 0，永久死寂（91,000 tick）
```

峰值：仅 6 群体 / 15 成员；分化 3 次。

### seed 42 —— 双物种稳态，侥幸存活

```
t=2000  PRED 灭绝
t=8000  herb/scav 灭绝
t=15000 omn 灭绝
t=15000 → 100000  fish=60 + deco=80 稳态（140 个体），群体 34-50 个持续存在
```

- 存活机制：**FISH_FILTER_GAIN=1.5 的免费滤食**（开放边界输入，不依赖草）+ DECO 矿化尸体
- `dissipation_ratio` 从 0.70 涨到 2.20（>1 是账本口径：分母只有 light_in，未含 fish filter_in；不是能量凭空产生）
- `tainter_slope` 持续为正且增长（吞吐-维护在单 clade 下为绝对差）

## 3. 四个核心发现（机制缺口）

### 发现 1：食物链断底 → 全系统死亡螺旋
herb 灭绝（t=6-8k）后：无 herb → 无尸体 → deco 断粮 → 全灭。**零种群是吸收态**——当前没有任何「生命再起源」路径（神之手已按定夺退役）。两次实验里世界永久死亡 79k-91k tick。

### 发现 2：herb 为什么灭绝？——待深挖
5000 tick 时 herb 还有 92-191 只，但 100k 时 t=7000 全灭。草量应充足。可能原因：hydration 耗尽（不主动寻水的代价设计）、群体角色系统抢走觅食能量、或草量循环在某个临界点崩溃。**需要单独诊断**。

### 发现 3：文化发明死锁（零 token 发明）
invention 算子只能「重组两个已知 token」——初始 registry 为空时**没有产生首 token 的路径**。Phase 37 的 (c,f,N) 框架从未被激活。10 万 tick 零发明零传播零失传。

### 发现 4：生态多样性崩塌
三个 seed 的分化事件总计 6 次（0-3/seed），且全是 DECO 单谱系。seed 42 存活期 herb/scav/omn 全灭只剩 fish+deco——**多物种生态退化为双物种**。选择层级 1→2 在群体出现时成立，但群体只依附于 DECO（seed 42 的 40+ 群体）。

## 4. 结论与下一步候选（待造物者拍板）

观测证明：**当前世界的「自主发展」在 10 万 tick 尺度上表现为「死亡螺旋 + 文化沉默」**。三个候选修复方向（均符合「接入现实规律」铁律）：

1. **生命再起源（Abiogenesis）**：允许无机环境在特定条件（热泉口/矿化活跃区）自发产生最原始的生命——现实世界真实发生（米勒-尤里实验、热泉化学演化）。这不是神之手（不是外部救援），是底层规则允许的化学→生命跃迁。**推荐优先**——否则世界死亡后永远无法重启，「完美自主发展宇宙」不成立。
2. **首 token 去锁**：给发明算子加 de-novo 路径（探索/试错产生第一个知识 token）——文化层从零启动的前提。
3. **herb 灭绝根因诊断**：先查清食物链底部为什么崩（hydration/群体能量分配/草量循环），再决定修不修。

建议顺序：3（诊断）→ 1（abiogenesis）→ 2（首 token）。诊断是其他两项的前提——如果 herb 死于 hydration 设计缺陷，那 abiogenesis 复活的生命也会很快死掉。
