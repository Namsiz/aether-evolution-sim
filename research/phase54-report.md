## 1. 调研发现：Phase 37 的「生态位构造」是空壳

`try_place_structure` 只注册结构 + 给放置者即时能量（`grass_mod × 10.0`）；**结构从不触碰世界的任何环境场**。这就是文化与分化五期以来无法耦合的根本原因——文化没有物理载体。

## 2. 实现：真实的结构→环境接线

- `structure_env: Vec<f32>`（每格草再生乘子，初始全 1.0）
- 放置结构时：半径 `STRUCTURE_ENV_RADIUS=3` 格内 `+= grass_mod × STRUCTURE_ENV_BOOST`，clamp `[0.5, 1.5]`
- 草生长路径乘上 `structure_env[i]`——**每一克额外草仍走阳光账本**（生长率乘子，非凭空加草）
- 衰减：`STRUCTURE_ENV_DECAY=0.998/tick`（半衰期 346 tick）——文化生态位必须持续维护才存在
- 衰减 pass 有 `decay_active` 短路（场全 1.0 时零成本）
- A/B：`structure_env_off()`；SaveState v20（场 + 开关 + 短路标志）
- 遥测可测：测试验证结构放置 → 邻域乘子偏离 1.0

## 3. 标定过程与诚实发现（本阶段最有价值的部分）

### 3.1 三轮标定
| 参数 | 结果（80k tick，seed 20261102） |
|---|---|
| BOOST=8, MAX=2.0, 衰减半衰期 6.9k | 922 结构，**零分化**（草场被结构饱和，生长翻倍） |
| BOOST=2, MAX=1.5, 半衰期 346 | 1402 结构，**零分化** |
| **A/B 因果确认** | 同代码 `structure_env_off` 臂：**3 clades / 2 speciations** ✓ |

### 3.2 因果链（营养级联）
```
结构提升草再生 → 初级生产 ↑ → HERB 能量/数量 ↑ → 尸体供给更稳定
→ DECO 的 80 成员根族稳态更稳 → 有效种群大且稳定 → 漂变减速
→ 遗传距离 80k 内达不到分叉阈值 → 零物种形成
```

**这是现实世界的映照**：农业提升承载力 → 生物多样性下降。文化「提高产能」的方向与「创造多样性」的方向是**相反的**。

### 3.3 决策
- 机制接线**保留**（架构正确：文化终于有了物理载体，测试可验证）
- **默认 OFF**（`STRUCTURE_ENV_ON=false`）——不交付一个反演化的默认世界
- 四锚点不变（默认 OFF = 零副作用，与 Phase 53 bit-exact）
- A/B 两组均保留在测试中（`structure_env_on` 显式开启验证 ON 臂行为）

## 4. Phase 55 的正确方向（由本期发现直接推出）

生态位构造要**支持**分化，必须**增强异质性**而非总量：
1. **异质性优先**：结构效果以「不同 clade 的结构类型不同」为核心——token 签名的正负符号自然分化（一个 clade 建增草结构、另一个建抑草结构）→ 空间异质化 → 生态位分化。当前实现已有符号（grass_mod 可正负），但 h 的总量提升淹没之
2. **DECO 直接资源**：结构作用于尸体分解速率/矿化循环（DECO 的直接食物链），绕过 HERB 营养级联
3. 或：结构效果改为「排除竞争者」而非「提升产能」（如局部抑制其他 clade 的觅食效率）——文化作为竞争武器
