## 1. 缺陷

Phase 58 §2.1：`reproduce()` 的 DECO 个性化阈值 = `0.96 × (2 − eff)`（selective 模式，再乘拥挤项 ≥1）。DECO 的 `max_energy = 100`，能量在摄食后 `min(energy, max_energy)` **精确截顶**，所以

- `0.96 × (2 − eff) ≤ 1` ⇔ `eff ≥ 0.958333…` 才可能达到阈值；
- `eff < 0.9583` ⇒ 阈值 > 100 % ⇒ **该个体在整个生命周期内永远无法开闸**（不是「难」，是「不可达」）。
- `DECO_MUT_SCALE = 5` 的物种形成出生会成批产出 `eff` 偏低的女儿支（Phase 58 实测 deco-C eff 0.771–0.828，余生 `ready ≡ 0`，5 980 tick 后老龄灭绝）。这是**机制缺陷**，不是设计：突变尺度与绝育概率被耦合在一起。

## 2. 映射设计

### 2.1 形式

```
legacy(eff) = 0.96 × (2 − eff)                     // Phase 7 原线
f(eff) = legacy(eff)                               if legacy(eff) ≤ KNEE
       = KNEE + span · x / (1 + x)                 otherwise
  x    = (legacy(eff) − KNEE) / span
  span = CEIL − KNEE,  KNEE = 0.96,  CEIL = 0.99
```

- **eff ≥ 1.0 完全不动**：`f(1.5) = 0.48`、`f(1.0) = 0.96` 逐位等于旧线；在 `legacy ≤ 0.96` 的整段（含所有 `eff ≥ 1.0`）直接返回旧值。
- `eff < 1.0` 段把旧线超出的部分**压进 `(0.96, 0.99)`**：`x/(1+x)` 在 `x=0` 处一阶展开为 1，所以 `f` 与旧线在 `KNEE` 处不仅连续，而且一阶导也连续（`df/dlegacy|₀ = 1`）；整体严格单调（eff 越低越难），上界严格小于 1（`eff = 0.5` 时 0.988235）。
- 只用 `+ − × ÷`，不引入任何超越函数 ⇒ native 与 wasm 的浮点结果逐位一致。
- **为什么选有理式而不是线性压缩**：`x/(1+x)` 在膝关节处自然饱和、无折点；线性方案会在 `eff=0.96` 处留下一个 0.038 的跳变（候选 a 的原式在 `eff=1.5` 处也不等于 0.48，必须分段才能满足端点，见 §2.3）。

### 2.3 候选 a 的问题（为什么不照抄）

任务给出的候选 a `0.96 + 0.04·clamp(0.96−eff, 0, 0.46)/0.46` 在 `eff=1.5` 处返回 **0.96**，不是 0.48；要满足端点必须分成 `eff ≥ 0.96` 走旧线、以下走斜坡，而旧线在 `eff=0.96` 的值是 0.9984，斜坡起点是 0.96 ⇒ **0.038 的跳变**。本期采用有理式软饱和，同时满足端点、连续与一阶连续。

## 6. 判读：为什么 102 的分化归零（本期最重要的负面发现）

### 6.1 旧分化引擎吃的是 bug 的副作用

Phase 56/57/58 反复测到同一件事：**DECO 满编（80）⇒ 零物种形成；DECO 掉档（34–60）⇒ 有物种形成**。而「掉档」的来源正是旧硬闸：初始 DECO 的 eff 是 `[0.5, 1.5]` 均匀分布（`ecology.rs` 的 `GenomeTemplate::Deco`），旧世界里有相当一部分 `eff < 0.9583` 的个体**占着容量却永不繁殖**。它们把有效繁殖群体砍掉一截，DECO 因此长期停在容量顶以下；一旦掉档，结构场才能把某个支系推过物种距离。

修好硬闸后，这批个体也进入繁殖池，DECO 在 102 上从 t=10k 起**恒定满编 80**（80k 与 200k 的每个 5k 采样都是 80），首分叉的前提消失，于是 0 事件。

### 6.2 能量精确截顶让「可育」没有中间地带

关键细节：能量是 `min(energy, max_energy)` **精确到 100.0**，不是渐近。所以任何 `阈值 ≤ 1.0` 都会在「吃掉一整具尸体、本 tick 能量=100」时立刻满足；`0.99` 与 `0.999999` 的差别只是窗口多几个 tick，不足以改变「满编」这个宏观结局。**CEIL 探针**（80k、seed 102、`CEIL=0.999999`）：DECO 轨迹仍是 20k/40k/60k/80k 全 80，**0 事件**。⇒ 归零不是 0.99 选得太松，而是「把不可达变成可达」这件事本身的必然结果。

### 6.3 三 seed 的方向

- **102**：旧世界靠「半绝育」维持 45 只 DECO、4 次物种形成；新世界满编、0 次。
- **42**：新世界首分叉提前到 3.24k（旧 6.60k），物种形成 2 → 4；两次灭绝都是**出生后存活 133k / 12.8k tick 的支系**（不是出生即绝育），属于人口学/竞争灭绝。
- **109**：旧 4 / 新 4，持平；新世界的低 eff 女儿支（eff 0.59/0.76）在 200k 仍存活。

也就是说：修复本身在个体层面完全成立（§5），但世界层面是一个**盆地切换**，不是单调改进。是否接受「102 归零」，是 Phase 60 的产品决策。

## 10. Phase 60 遗留

1. **分化触发与生育修复解耦（首要）**：Phase 56 的分化引擎实际吃的是「旧硬闸把 DECO 压在容量顶以下」这一副作用。修好硬闸后 102 满编、0 事件。Phase 60 需要一个新的、不依赖「半绝育人口」的掉档/分化触发（可选方向：让结构场直接改变局部容量、或让 niche 构造反馈修改 `MAX_DECO` 的局部有效值；不要再用「不可达阈值」当刹车）。
2. **避免用「不可达」做难度梯度**：能量是精确截顶，`阈值 ≤ 1` 与 `阈值 = 1` 在实际出生率上几乎没有中间地带。若 Phase 60 仍要保留 eff→难度的梯度，应改成**不占能量闸**的代价（例如 `repro_cooldown × (2−eff)`、或出生能量成本 × eff 惩罚），否则任何「饱和到 1 以下」的映射都会把低 eff 变成满速繁殖。
3. **CEIL 参数化**：本期证伪了「CEIL 接近 1 就能保住分化」（0.99 与 0.999999 在 102 上都是 0 事件），所以 CEIL 不需要作为 Phase 60 的调参旋钮；若改用冷却/成本型难度，再重新标定。
4. **seed 池扩样**：3 seed 的物种形成 10 → 8、灭绝 2 → 2，方向不单调。任何后续「分化率」判据至少 5 seed，并区分「出生即绝育」与「出生后人口学灭绝」。
5. **观测器三列已产品化**（`mean_eff` / `deco_ready` / `min_pair`），Phase 60 可省掉临时诊断器；逐 clade 出生计数仍建议做成引擎级计数器（本期用 id-diff 临时器）。
